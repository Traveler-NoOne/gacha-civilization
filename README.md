# 抽卡文明 · 可玩 Demo

把设计文档《抽卡文明》里已经写清楚的部分做成了一个**能跑起来、能玩一轮**的 Godot 4 原型。当前版本 **v1.8.21**（量子之海 · 黑体 UI · 首套资源图标 · 真实地形）。

**世界观（v1.6 重设）**：我们文明的世界**漂浮在量子之海中**——它是海里无数「世界泡」中的一枚。通过世界泡系统，我们可以向周围的世界泡进行交互。

- **召唤系统**：向附近的世界发出信号，牵引其中的存在（有时是个体，有时是被遗弃的装备）。附近的世界泡**大多已濒临末日**，所以受召唤者往往**愿意留下**——留下，比回去强。但有时，伴随着我们开辟的通道，也有有一些量子之海中的存在尝试寻找漏洞挤进来，不过大多数没有那么聪明，不会每次都有不速之客跟随而来。
- **打捞系统**：从**量子之海**汲取混沌物质（以太涨落凝结），取出并凝结后才知道捞到了什么；直接从海里捞更容易被盯上。
- **发展系统**：把**一整片世界泡包裹进来**——凭空多出一处大型矿脉或高产出原油层，也几乎必然把泡里的敌人一起包进来。

> 这一套设定的用处：**抽的不是"从活得好好的平行世界抓人"，而是收留末日世界泡的来客**——把"拐卖人口"的嫌疑拆掉了。
> ~~开局赠送的 5★ 公民 **格蕾修**就是这条设定的具象化：她是前文明「方舟计划」的乘员，带着旧文明的全部遗产漂流、寻找新的世界——**她本身就是第一位"客人"**。~~
>
> 以上内容将在未来版本中进行替换，开局赠送的五星公民将更改为**华**，是前文明 火种计划 的实行者。在前文明时期，我们仍然是虚数之树上的一片叶子，但是现如今，出于不明原因，我们现在落入了量子之海，世界只剩下了一小片。

除了少量资源图标与格蕾修的立绘（作者自绘、切片而来）之外，视觉元素基本用**几何多边形 + 文字**代替：三角形、正方形、菱形、六边形、圆形、星形、长方形，配合稀有度配色。

> 界面字体：**全局黑体**（项目级主题 `scripts/ui/ui_theme.tres`，用 `SystemFont` 读系统黑体族，**不打包字体文件**）。项目里没有字体文件，若不显式指定，Godot 会用内置默认字体 + 系统回退链去猜中文，小字号下很容易猜出一个难认的字（`[b]` 粗体还会再走一套）。

## 设计理念与定位

**核心命题：抽卡本身不是负面玩法，"付费"才是。**

- 抽卡的本质就是**「随机结果」**：流程上是"选卡池 → 直接出结果"，**出什么完全不可预料**。本作不替抽卡辩护——大方承认它随机，然后把**"怎么用"**做成真正要玩的东西（吸血鬼幸存者的升级三选一、杀戮尖塔的卡牌与遗物，本质都是抽卡；它们不挨骂，因为不花钱）。
- 单机版的解法：**把"付费成本"换成"策略代价"**。白嫖可以，但你得付得起后果。
- **受众**：冲着米游内容来的 4X 玩家。不刻意扩张玩家群体，而是把玩法做深，让喜欢的人玩得爽。（想龟缩不抽卡、只走现实科技树的，去玩文明 6 更合适——那不是本作的受众。）
- **运气哲学**：文明本来就由运气塑造（小冰期、铁骑）。**抽到什么是纯随机的、不由你定；但"抽到之后怎么办"由你定。** 要的是**"可解释、可响应的局势"**，不是不透明的骰子——所以威胁都是地图上的**对象**（可清剿 / 绕开 / 硬碰）：你看得见它，也能对它做决定。
- **不做动态难度（不做 rubber-band）**：破局 build 需要一个配得上它的靶子，终极威胁就是那个陪练。威胁是固定的靶子，玩家的任务是滚雪球滚过去——否则"我成神了"的爽感会被系统抹平。

### 三卡池 = 三个文明尺度，代价随尺度递增

| 卡池  | 尺度     | 抽到      | 代价                  |
| --- | ------ | ------- | ------------------- |
| 轮换  | 个体     | 强大的单位   | 地图上概率生成敌对单位（单位换单位）  |
| 资源  | 领地     | 发展据点    | 地图上概率生成敌对据点         |
| 发展  | **范式** | 一条全新科技树 | 生成足以威胁整个文明的**终极威胁** |

### 三条范式树（科技树是"抽出来的"）

- **默认 · 蒸汽 / 电气**：不抽发展池时，文明走的就是现实地球的科技路线——基建、产能、常规部队，稳。
- **元素力（原神）**：抽到「元素地脉」之类的内容，就有开启**元素力科技树**的潜力。
- **崩坏能（崩坏）**：抽到「律者核心」之类、能长期获取崩坏能的内容，就有开启**崩坏科技树**的潜力。

开启新范式会在地图上产生**终极威胁**——这是白嫖新科技树的代价。

### 据点 / 地块 / 建筑（v1.3.1）

- **据点 ≠ 地块**：据点可包含多个地块。本作暂时只有「首都」一个据点（所有领地都归属它）。
- **建筑修在地块上**：每个地块有**可用土地**（默认上限 1.0，未来科技提升）。一个地块可放多个建筑（**同种可重复**），只要土地够。
- **扩张消耗「行政点数」**（不是生产力）：行政点数越多，扩张越便宜（**行政影响力**，最高 −50%）。
- **规划队列**：生产力不足时也能修建——项目排进据点的**规划队列**，每周期生产力**先填队列**，队列无需求时才储存，且**盈余存储上限 20**。
- **行政点数收支**：基底每周期 +1；击杀敌人按类型给限时产出 buff、友军阵亡给限时 debuff，另有「当期收支项」正负加成（数值见 `constants.gd`）。
- **掌控力**（预留，本版不接行为）：据点离首都越远掌控力越低，过低会自治 / 独立，甚至变危险据点。

> 建筑系统的入口是**右键地块 → 🔨 球形按钮 → 修建浮窗**（v1.8.5）；据点管理窗口的下半段是**规划队列**。

## 一、运行方式

### 用编辑器打开

```
Godot 4.7 → 导入 → 选择本目录的 project.godot → F5
```

### 命令行直接运行

```powershell
$godot = "C:\Program Files\Godot_v4.4.1-stable_mono_win64\Godot_v4.7.2-stable_win64_console.exe"
# 注意：上面那个目录名写的是 4.4.1，但里面的 exe 是 4.7.2 ——
# 当初安装时目录名没跟着改，不是笔误。
& $godot --path "D:\Project\godot\抽卡文明-legacy"
```

### 验收方式（自检套件已删除，2026-10-17）

`tests/` 下的 4 项无头自检和截图脚本**已经全部删除** —— 无头自检遇到语法 / 解析问题会**静默卡住**，
修一次比手检还费时间。现在一律**读代码检阅 + 编辑器里手检**，不要再新写自检脚本。

```powershell
$godot = "C:\Program Files\Godot_v4.4.1-stable_mono_win64\Godot_v4.7.2-stable_win64_console.exe"

# 导入资源 / 注册 class_name（新增或替换带 class_name 的脚本之后必须跑一次）
& $godot --headless --import --path "<项目目录>"
```

**世界生成怎么验收**：主菜单 → 新游戏 →「出图内容」选 `地图（旧生成器）` 或 `★ 新地图（噪声版）`
→ 点「只出图看看」。图落在项目 `preview/`（控制台会打印绝对路径）；
**同一个种子出两次 → 两张图应当逐字节一致**。

> ⚠️ **新增 / 替换 `art/` 下的图片后**，先跑一次 `& $godot --headless --import --path <项目>`（或打开一次编辑器）让 Godot 导入，否则游戏里 `load()` 拿不到纹理。
> **带 `class_name` 的脚本从 git 恢复或新建之后也一样**：不 `--import` 的话全局类名没注册，
> 依赖它的脚本会编译失败，表现常常是"某个函数不存在"，很容易被当成语法错误。
>
> ⚠️ 出图工具（`scripts/worldgen/preview.gd`）**必须带窗口跑**：`--headless` 下 `SubViewport` 拿不到纹理。

### 单位与战斗系统

**职业**决定克制关系，暂时五种：

| 职业   | 射程            | 克制        | 被克制       |
| ---- | ------------- | --------- | --------- |
| 近身战士 | 1             | 防御者、支援者   | 远身战士、投射者  |
| 远身战士 | 1             | 近身战士、防御者  | 投射者       |
| 投射者  | **2**（可隔一格攻击） | 近身战士、远身战士 | —         |
| 防御者  | 1             | —         | 近身战士、远身战士 |
| 支援者  | 1             | —         | 近身战士      |

- 克制命中的伤害 **+30%**，被克制 **−20%**
- 防御者额外**小幅度减免**所在格子与队伍中单位所受伤害（−20%），对投射者的伤害**大幅度减免**（−60%）

**位阶**决定战斗时的属性倍率，倍率由经验进度在区间内插值：

| 位阶  | 倍率区间      | 经验上限 | 设计理念                                |
| --- | --------- | ---- | ----------------------------------- |
| 募集军 | 0.6 ~ 0.8 | 100  | 刚招募，对战斗并不熟练，甚至常常犯错，因此有负修正           |
| 正规军 | 0.8 ~ 1.1 | 200  | 招募已久 / 训练已久 / 经历惨烈战斗，有丰富经验，不会再犯低级错误 |
| 角色  | 1.0 ~ 2.0 | 500  | 特殊事件转换或抽卡获得，具备独特性，不会产生负修正           |

- 经验可以通过**周期循环**缓缓增长，但每个单位**最多通过这种方式获得 100 点**；其余经验来自战斗
- 经验满后可以**晋升**到更高位阶（募集军 → 正规军 → 角色）

**编队与容量**：一个世界格子最多存在 **4** 个单位；一个队伍最多同时存在 **4** 个单位。

**战斗结算**：除非有专门设计，否则都是个体单位对个体单位造成伤害。目标格子存在多个单位时需要专门选择；**敌人 AI 面对存在多个玩家单位的格子时随机选择，只有高危及以上的敌人才会考虑克制关系**（Demo 里「危险据点」与「终极威胁」视为高危）。

### 核心循环（周期结算）

每点一次「结束周期」会依次结算：

1. 建筑产出（按指派人力 × 每级加成）
2. 领地基础产出（每块领地 +0.6 生产力，让扩张本身有正收益）
3. 维护消耗（建筑维护 + 人口食物）；维护优先扣生产力，不够时按 2 倍货币抵付
4. **生产力入队列**：剩余生产力**先填据点的规划队列**，填完还有多的才储存，且**盈余存储上限 20（超出作废）**
5. 人口增长（受幸福度、住房上限、粮食储备影响）
6. 世界演化：高危据点生成游荡敌人 → 游荡敌人移动 → 终极威胁推进 → 敌人攻击相邻我方地块 → 超额敌人消散 → 资源点再生
7. 世界泡货币结算：秩序结晶（按玩家等级）、凝聚力（幸福度数值 × 文化率倍率）
8. 行政点数结算：基底每周期 +1 ＋ 限时 buff/debuff ＋ 当期收支项（每条正 +0.1 / 每条 0 或负 −0.1）
9. 单位经验随周期缓增；稳定度过低会流失人力
10. **自动存档到槽位 1**

### 稳定度公式（严格按文档）

```
稳定度 = ( (玩家总战斗力 / 敌人总战斗力) × (空白格子数 / (空白格子数 + 1)) )
        × (1 − (敌人数量 / 地图总格子数) × 0.5)
```

## 五、数值实现说明

建筑设计文档里写了公式的建筑全部按原文实现（每级人力上限、每人产出、每级追加、升级消耗递增、等级上限），例如：

- **经典田地**：每级 2 人力，每人 1.3 食物，每级 +0.35，−2 幸福度；消耗 10 生产力，升级 +10，上限五级
- **经典面包坊**：+6 幸福度（每级 +0.6）；消耗 20 生产力，升级 +15，上限五级
- **经典磨坊**：每人耗 1 食物、产 2.6 食物（净 +1.6），每级 +0.35 食物；消耗 25 生产力，升级 +20，上限五级
- **经典工坊**：每级 2 人力，每人 1.5 生产力 + 0.4 科研点，每级 +0.35 生产力；消耗 20 生产力，升级 +15，上限五级
- **经典市场**（v1.6.2 新增）：每级 2 人力，每人 **1.6 货币**，每级 +0.35 货币；消耗 25 生产力，升级 +20，上限五级
- **经典矿场**：每人 1.1 生产力，每级 +0.35；若所在格有矿物资源点则额外产出对应矿产 +1（每级 +0.35）；消耗 8 生产力，升级 +12，上限五级
- **炼金所**：每人 5.5 生产力，每级 +1.5；消耗 180 生产力 + 400 货币，升级 +50 / +100，上限三级
- **经典训练场地**：每级 1 个训练槽位；消耗 20 生产力，升级 +15，上限五级
- **经典民居**：按住房比插值给 **1~10 货币/级**，幸福度 ±10；消耗 20 生产力，升级 +20，上限五级
- **经典学院**：每级 2 人力，每人 0.9 科研点，每级 +0.35；消耗 40 生产力，升级 +45，上限五级
- **黑土学院**：每级 2 人力，每人 3.2 科研点，每级 +1.2；消耗 300 生产力 + 2400 货币，升级 +100 / +800，上限三级
- **经典仓储**：每级 +50 具体资源存储上限（货币除外）；消耗 30 生产力，升级 +25，上限五级

> v1.6.2 的平衡口径：每级维护 **0.25 生产力**，所以**每级加成必须 > 0.25**（否则升级是负收益）；经济建筑回本目标 4~8 周期。完整对照见 `docs/版本记录/v1.6.2.md`。

文档没有给出的数值（例如「秩序结晶根据等级结算」的具体系数、地图扩张单价、稳定度对人口的惩罚）都在
`scripts/data/constants.gd` 里作为**演示用占位值**集中定义，方便后续调整。

## 七、已知的取舍

1. **稳定度死亡螺旋**：文档的稳定度公式在稳定度低时会减少人力，而人力减少又进一步降低稳定度。
   Demo 里加了保底人口（不低于 2）与敌人数量上限来避免新玩家直接卡死。
2. **终极威胁**：文档里它是终局机制。Demo 为了让玩家能看到它，允许通过「发展抽卡」主动召唤，
   并且在战力足够时可以清剿。
3. **抽卡货币**：文档说秩序结晶「根据玩家的等级结算」但没有给等级定义，Demo 用
   `1 + 科技数 + 领地数/4 + 周期/10` 近似。
4. **卡组名与文明组名**：卡组名改成了文明组名（原神组 → 提瓦特、崩坏组 → 崩坏本征、`绝区零组 → 绝区零）。
   旧组名的别名已随"不做旧档兼容"一起删掉（`GROUP_TO_CIV` 现在只有新名）—— 与之配套的是第 14 条。
   绝区零组 → 绝区零）。`card_db.gd` 的 `GROUP_TO_CIV` 同时保留新旧两套写法，用于兼容旧存档。
5. **职业与位阶的数值区间**：文档只给了「0.6~0.8 / 0.8~1.1 / 1.0~2.0」这样的区间，并说明
   「倍率由经验进度决定」。Demo 采用**在位阶区间内按经验进度线性插值**，这是一个合理的具体化。
6. **敌人也有职业**：文档只定义了玩家侧的克制关系。Demo 给敌人也分配了职业（危险据点=防御者、
   终极威胁=投射者、游荡敌人按战力哈希分配），这样克制关系在战斗里才有实际意义。
7. **作弊开关与自动存档周期的持久化**：它们是玩家的**全局偏好**，存在 `user://settings.cfg`
   （Autoload `AppSettings`），与存档解耦——开启后新游戏 / 继续 / 读档都保持。顶部栏会出现
   红色「作弊」按钮提醒。要关掉就回主页面 → 反馈 → 取消勾选。
8. **自动存档间隔的判定**：用「周期数 % 间隔 == 0」来判断是否该存档；
   设成 3 就是第 3、6、9… 个周期各存一次。存档槽位仍然是自动存档专用的槽位 1，不会覆盖手动存档。
9. **不做动态难度（不做 rubber-band）**：见「设计理念与定位」——威胁是固定的靶子，
   不随玩家战力上涨而变强，保留"滚雪球成神"的力量幻想。
10. **土地占用 0.3~0.6**：每个地块默认可用土地上限 1.0，因此一个地块通常只放得下 **2~3 个建筑**，需要靠扩张把建筑铺到多块领地上（这也是建筑改由「右键地块修建」的意义）。未来科技可提升上限。
11. **生产力盈余上限 20**：大额建筑（如炼金所 180 生产力）会**跨多个周期排队**完成，这是文档既定的「规划队列」设计；价值取自 `constants.gd` 的演示占位值。
12. **行政点数**：v1.3.1 新增的扩张货币。基底 +1/周期、击杀 buff、收支项、行政影响力都是**演示占位值**，需要在**实机试玩**里观察节奏后再调（常量集中在 `constants.gd`）。
13. **存储上限（v1.4）**：生产力 20、科研点 200、具体资源（货币除外）100 ＋ 经典仓储每级 +50。超出即夹取/作废；数值均为演示占位。科研上限须 ≥ 120 才能研「炼金-黑土」。
14. **旧存档不兼容（1.0 期的既定决定）**：`SAVE_VERSION` 不符的存档会被**直接删除**，并在游戏里提示"存档已过期，请新开一局"。1.0 期数据模型还在变，不做迁移；兼容留到 2.0 再谈。
