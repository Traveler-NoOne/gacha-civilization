# 未来「摩拉」图标 · 需求规格（高级资源，2.0 之后再上）

> v1.6.2 起「摩拉」已从资源表移除、原槽位改名「货币」，那一格现在由**古典方孔钱**（art/icons/currency.png）占用。
> 这份规格留作**将来「摩拉」作为另一种高级资源回归时**的图标底稿。

## 一、交付口径（和其余 14 个图标严格一致）

| 项 | 值 |
| --- | --- |
| 逻辑尺寸 | 32 × 32（1 单位 = 1 逻辑像素） |
| 描边 | `#241b2e`，宽度约 1.6 单位，画在填充层之下 |
| 明暗 | 平涂 + 一层暗部 + 一层高光，**不用**渐变、阴影滤镜、半透明 |
| 导出 | 4x = 128×128（推荐）、1x = 32×32；缩放只改倍率，不改根尺寸 |
| 落位 | 可加在 `art/icons.resources.svg` 里当第 15 格（三行八列 = 256×96），或单独 `art/mora.svg` |

## 二、推荐构图（两版任选）

### A. 单币（最简）
以 `(16, 16)` 为圆心：

- 描边圆 `r = 10.6`
- 币面圆 `r = 9.1`（金主色）
- 币缘环：外圈留 ~1.6 宽的浅金一圈（`mora-light`）
- 内圈细线：`r ≈ 7.4` 的一圈暗金，线宽 ~0.8
- 中心徽记：**自创**纹样，三选一
  - 方孔（中式铜钱）
  - 四角星（和行政点数那格同构，只是尺寸更小、配色不同）
  - 两条交叉弧线 / 抽象"币"字形
- 高光：左上 1/4 一段弧形高光，或一个椭圆高光斑

### B. 币叠币（"货币"辨识度最高）
前币完整（同心圆同上）；后币在**左上方**露出约 1/4，整体偏移 3~3.5 单位。两枚叠放会立刻读成"钱"。

> 32px 下细节会糊，**中心徽记最多 2~3 个笔画**，宁简勿繁。

## 三、配色（可直接复制进 `art/icons-palette.json`）

```json
"mora":       "#e8c15a",
"mora-dark":  "#b98f22",
"mora-light": "#fdf3c0"
```

与整套图标同源：暗金 `#b98f22` 做暗部与内圈，浅金 `#fdf3c0` 做高光与币缘，主色 `#e8c15a`。

## 四、同人安全提醒（你说了会临摹后改动，这条就是给你的依据）

- 只取 **"金色硬币"** 这个通用形态——公版意象，谁都能用。
- **不要**临摹官方摩拉的成体浮雕纹样、字体、兽首/花纹细节；那些属于米哈游版权。
- 你临摹后**换掉中心纹样、微调比例**，画面的"独创性/改编幅度"就足够了；界面上也**不直接使用官方素材**。
- 配合 README 里那条免责声明（非官方同人、与米哈游无隶属、非商业），风险就压到最低了。

## 五、接入建议（可选）

想一键换色/做暗色版，可在 `icons-palette.json` 里加 palette 变体：

```json
"variants": { "mora-bright": { "mora": "#f4d071", "mora-dark": "#c69a2a" } }
```

渲染时 `--variant mora-bright` 即可。
