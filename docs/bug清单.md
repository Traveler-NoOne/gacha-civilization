## 逐条

### 1. 🔴 据点管理窗口的提示指向已删除的页面
- **证据**：`08b_stronghold_info.png`、`08d_stronghold_labor.png`
- **实际看到**：窗口下半段「规划队列（生产力）」的空状态写着
  「队列为空。到「世界 → **地块规划页**」或右键地块选择…」
- **为什么是 bug**：那个「地块规划页」（旧右侧规划面板）在 **v1.8.5 已删除**。玩家照这句话找不到任何入口。
- **推测位置**：`scripts/ui/panels/stronghold_panel.gd`（空队列提示文案）
- **修好怎么验**：这两张图里不应再出现「地块规划页」字样；应指向**右键地块 → 🔨** 或据点管理窗口本身。
- **置信度**：高

### 2. 🔴 作弊菜单的「摧毁敌对单位」列表塌成 0 高度
- **证据**：`19_dialog_cheat.png`
- **实际看到**：「当前大世界敌对单位：**6 个**」下面**一片空白**，直接就是 [摧毁全部敌对单位]。
  上面的说明还写着「可以选中大世界中的任何敌对单位直接摧毁」。
- **为什么是 bug**：逐个敌人的行（名字 + 战力 + [摧毁] 按钮）**一行都没显示** → 单个摧毁功能等于不可用。
- **推测位置**：`scripts/ui/game_screen.gd` 的 `_open_cheat_menu()` —— 敌人列表用的是
  `ScrollContainer` + `custom_minimum_size = Vector2(0,0)` + `EXPAND_FILL`，
  而它**外面还套了一层 `UIKit.scroll(v)`**：嵌在滚动容器里时，子项只拿到**最小高度**（0）→ 塌成 0。
- **修好怎么验**：`19` 图里应能看到 6 行敌人（或至少高度足够显示若干行并自带滚动）。
- **置信度**：高（现象）／中（成因）

### 3. 🔴 `20` 里没有单位操作窗
- **证据**：`20_unit_panel.png`
- **该看到**：点中棋子图标后，左下角弹出**单位操作窗**（立绘 + 攻/血/移动 + 攻击/移动/驻军三个按钮）。
- **实际看到**：**只有地图**，外加一个写着 `0.0` 的小方块（见 #7）。
- **为什么是 bug**：这是 v1.6.1 的核心交互（攻击/移动/驻军都在这个窗里）。若真没弹出，战斗操作无法进行。
- **待查**：先确认图上那个 `0.0` 小方块是不是**塌掉的单位操作窗**（若是，则 #3 与 #7 是同一个根因）。
- **修好怎么验**：`20` 图里应看到完整的单位操作窗。
- **置信度**：中（现象确定，但"完全没窗"和"窗塌了"要区分）

### 4. 🔴 招募选地模式没有任何视觉提示
- **证据**：`21_recruit_pick.png`
- **该看到**：进入"招募 → 选地块"模式后，可部署地块应**高亮**，或有提示文字。
- **实际看到**：地图与提示行**与平时一模一样**（顶部提示仍是「左键拖动平移 · 滚轮缩放 · 左键点击地块查看详情 · 中键回到首都」）。
- **为什么是 bug**：玩家点了"招募"之后**不知道要做什么**，只能乱点。
- **推测位置**：`scripts/ui/views/view_world_page.gd` 的选地模式渲染 / 提示行
- **修好怎么验**：`21` 图里应能一眼看出"正在等你选地块"。
- **置信度**：高

### 5. 🔴 设置里的快捷键说明过期
- **证据**：`02b_dialog_settings.png`（「操控设置」一节）
- **实际看到**：「快捷键：**1-5 切换功能页**，空格 = 结束周期，Esc = 关闭弹窗。」
- **为什么是 bug**：v1.8.7 已经把快捷键改成 **1 / 2 / 3**（至宝 / 世界泡 / 世界），管理页与日志都不再是一级入口。
- **推测位置**：`scripts/ui/menu_screen.gd`（设置弹窗的说明文字）
- **修好怎么验**：`02b` 图里应写 1/2/3。
- **置信度**：高

### 6. 🟡 菜单类弹窗半透明，底下内容透上来（**仍然存在**，v1.8.12 只修了"底部空白"）
- **证据**：`02b_dialog_settings.png`、`02c_dialog_feedback.png`
- **实际看到**：弹窗面板能**透出**主菜单的「抽卡文明」标题和「开始游戏 / 继续游戏 / 新游戏 / 读取游戏 / 游戏设置 / 退出游戏」。
- **为什么是 bug**：和 v1.8.4 修过的"据点管理窗口鬼影"**同一类问题**（浮窗底色 alpha 不够）。菜单这边没跟着修。
- **推测位置**：`UIKit.dialog(...)` 的底色，或菜单侧对它的覆盖
- **修好怎么验**：`02b` / `02c` 里弹窗应**完全不透明**。
- **置信度**：高

### 7. 🟡 鼠标附近多出一个只写 `0.0` 的小方块
- **证据**：`08e_tile_menu.png`（方块里还能看到 🔨 球）、`20_unit_panel.png`、`21_recruit_pick.png`
- **实际看到**：三张图里，鼠标点过的地方都有一个**很小的深色方块**，内容基本只有一个 `0.0`
  （`08e` 里还有一个修建球图标）。
- **为什么可疑**：右键菜单本该是**球形图标按钮**（只有 🔨，没有数字）；`20`/`21` 里更不该出现它。
- **待查**：需要看代码确认这个方块的归属（很可能是**某个控件塌成极小尺寸**，或**多渲染了一个数值 Label**）。
  若是"塌陷"，大概率和 #2 / #3 是同一种毛病（内层控件在滚动/容器里只拿到最小高度）。
- **修好怎么验**：`08e` 只应有球形按钮；`20` / `21` 里不应有这个方块。
- **置信度**：中（现象确定，归属未定）

### 8. 🟡 人力页行末括号数字无标注，且与修建浮窗疑似不一致
- **证据**：`08d_stronghold_labor.png` vs `08g_build_selected.png`
- **实际看到**：人力页每行是「**经典学院 Lv.1（-2.0）**」「**经典田地 Lv.1（0.0）**」「经典工坊 Lv.1（0.0）」；
  而修建浮窗里「经典田地」的效果写着「幸福度：**基础 -2.0**，每级 +0.0」。
- **为什么可疑**：① 括号里的数字**没有任何标注**，玩家不知道它是什么；
  ② 若它是幸福度，则「经典田地」两处对不上（-2.0 vs 0.0）。
- **修好怎么验**：两处数字要么一致，要么在界面上说清括号里是什么（例如写成「幸福度 -2.0」）。
- **置信度**：中

### 9. 🟡 游戏内版本号仍是 v1.7.2

- **实际看到**：「当前版本：抽卡文明 Demo **v1.7.2**（量子之海·黑体 UI·首套资源图标）」
- **说明**：这个字符串来自 `Consts.DEMO_VERSION_FULL`，加载界面副标题也在用同一个。
  不确定是"Demo 版本号只在发布点才动"还是漏更新 —— **需要你定要不要改**。
- **修好怎么验**：`02c`（以及 `01b_loading`）里显示你想要的版本号。
- **置信度**：高（现象）／待定（是否算 bug）
