## 本版修复的 Bug

| 问题 | 原因与修法 |
| --- | --- |
| 抽到多个角色后，至宝角色页的单位列表点不中 | 原来每行放了一个「全屏透明按钮」，但它被 `move_child` 插到了图标/文字**之前**，于是后面的兄弟节点盖在它上面、吃掉了鼠标事件；单位一多、行内容变长后尤其明显。改为**整行就是一个 Button**，子节点统一设为 `MOUSE_FILTER_IGNORE` 只负责显示 |
| 所有面板/按钮/弹窗的描边都看不见 | Godot 4.7 的 GL Compatibility（OpenGL）后端**不会绘制 `StyleBoxFlat` 的 1px 边框**（2px 同样不可靠，4px 才画）。在 `UIKit.panel_style()` 里加了 `MIN_BORDER_WIDTH = 3` 统一兜底 |
| 管理页地块详情文字重叠 | `RichTextLabel` 在固定高度下内部重排异常，改为用 `Label` 逐行渲染 |

## 遗留到 v1.3 的问题（当时的状态）

- 作弊勾选状态一开始被存进了 `GameState.state`（属于**存档状态**），导致每次 `new_game()` / 读档都会被重置回默认 false → v1.3 才修（移到全局 `AppSettings`）。
- 作弊菜单比屏幕还高、底部按钮点不到；`CheckBox` 在 GL Compatibility 下不绘制勾选框图标 → v1.3 才修。
