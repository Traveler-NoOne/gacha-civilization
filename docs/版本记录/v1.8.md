# v1.8 · 大重构：世界升格为 root（10 段）

> 一句话：**把"世界系统是五个平级页面之一"改成"大世界是舞台本身，其他都是舞台上的窗"。**
> 另外补了四样一直缺的东西：**政事系统**、**右键修建**、**简约地块信息**、**加载界面**。

## 为什么要这么改（这是本篇的重点）

- **4X 游戏的大地图本该是 root。** 我们原来是"五个一级页面"的平级结构，每次看地图都要"切"回来。
- **贴合设定**：世界泡就是舞台本身，其他系统是"在这个舞台上打开的窗"。
- 顺带解决了一个真实的体验问题：**地图不能是"一个页面"** —— 它得一直在，因为你随时要看它。

## 这一段踩过的坑（值得留在历史里）

1. **撤入口要 grep 它在测试里的所有别名**：日志从一级按钮搬走后，截图脚本里除了"拍日志页"那张图，
   后面**还有一段切日志子页签的代码**；管理页撤掉后，`diag_v16` 里还有 `views["manage"]`。
   症状分别是 **120 秒超时只出 29 张** 和 **TIMEOUT（脚本中途死掉）** —— 都不是"偶发"。
2. **删大块代码：锚点必须唯一 + 删前先断言行数**。我用"最后一次匹配"找结束锚点，
   结果匹配到新写的同名行，**一次删掉 120 行、把 `_switch_view` 也带走了**（表现是 1 个 Parse Error + 5 个 TIMEOUT）。
3. **`\t` 在 PowerShell 文本里不是制表符**，锚点静默失效，文件进入"新旧两套按钮并存"的半迁移状态。
4. **GDScript 的 lambda 按值捕获局部变量**：测试里 `connect(func(): done = true)` 改不到外面的 `done`，必须用成员变量。
5. **`Time.get_ticks_msec() - Time.get_ticks_msec()` 是自己减自己**，写成循环条件就是死循环。
6. **浮层摆位别用"锚右上 + 负偏移"**：锚点若在 `add_child` 之前设，还没有父节点可参照 → 负偏移被当绝对坐标。
   统一改成 **`TOP_LEFT` + 按屏幕尺寸算 + `resized` 重摆**。
