# v1.6.1 · 驻军归位 + 两处显示修复

> 来源：`抽卡文明 更新指导v1.6.1.docx`（云盘）。

## 1. 驻军功能搬到「单位操作窗」

- **地块规划页里的驻军面板（驻守列表 + 撤回 + 待命单位派驻）整块删除**。
- 改到：**世界 → 点单位 → 左下角操作窗**，作为 **「攻击 / 移动」之后的第三个按钮**。
- 按钮语义（本期定义，见下方"说明"）：
  - 点「**驻军**」→ 该单位**驻守在当前地块**：维护费打折（**领地内 −60% / 领地外 −10%**），代价是**不能移动、不能攻击**。
  - 点「**解除驻军**」→ 恢复行军状态：维护费**全额**，但可以自由行动。
  - 驻军中时，操作窗里会标出「［驻军中］」，且「攻击 / 移动」两个按钮**置灰**。
- 配套：单位新增字段 `garrisoned`（含旧存档补齐）；`unit_upkeep_of()` 的折扣改为**只在驻军状态生效**（v1.5 是按"是否在我方地块"给折扣，等于默认所有人都在打折）；`move_unit` / `unit_attack` 在驻军状态下直接拒绝并提示。

> **说明**：指导书只说"作为攻击、移动之后的第三个按钮"，没有定义它的效果。这里按 **v1.5 原文**（"驻军状态时，领地内减 60%、领地外减 10% 维护费"）把"驻军状态"落成了一个**显式开关**，并给了它一个代价（不能行动）让这个按钮成为一个真实取舍。如果你想要的是别的效果（例如只是把单位钉住、或者驻军加防御），说一声我改。

## 2. Bug 修复：领地上的单位在领地外不显示

- 根因：`hex_map_view._draw_tile()` 里驻军标记被 `if owner == "player"` 挡住了，所以单位走到**无主地块**上就不画。
- 改为 `if owner != "enemy"` —— 只要格子上有我方单位就画。

## 3. Bug 修复：操作窗左边没有立绘

- 根因：v1.5 做操作窗时只排了「名字 / 数值 / 按钮」的竖排，漏了立绘。
- 现在操作窗是 **左立绘 + 右信息**：左边 `GeoIcon` 立绘（按单位的 `kind` 与稀有度配色），右边是名字、位阶·职业（驻军时带「［驻军中］」）、攻/血/移动力，下面是三个按钮。
- 顺带把**底部队列**也改成了真正的"立绘窗口"：该格 ≥2 个单位时，每个单位显示成 **立绘 + 名字**（此前只有名字按钮）。

## 改动文件

- `scripts/ui/views/view_world_page.gd`：删除 `_refresh_garrison()` 与调用；单位操作窗重写（左立绘 + 第三个「驻军」按钮）；底部队列改立绘窗口。
- `scripts/ui/hex_map_view.gd`：驻军标记不再限定我方地块。
- `scripts/core/game_state.gd`：新增 `toggle_garrison()`；`garrisoned` 字段与旧档补齐；`unit_upkeep_of()` 折扣改为驻军专属；`move_unit` / `unit_attack` 加驻军拦截。
- `scripts/data/unit_db.gd`：两个单位工厂补 `garrisoned` 默认值。
- 测试：`tests/diag_v15.gd` 维护费断言按新规则更新（行军全额 / 驻军打折）；`tests/diag_v16.gd` 新增第 6 节「驻军：维护费打折 / 禁止行动」。

## 验证

- **11/11 自检全部 exit 0、0 失败**（含 diag_v15 / diag_v16）。
- `diag_v16` 第 6 节实测：行军维护 0.50 → 驻军 0.20（领地内 ×0.4）；驻军时移动被拒；解除驻军成功。
- 截图（非 headless，带看门狗）36 张全成，目视确认：操作窗左侧有立绘且三个按钮齐全、底部队列是「立绘 + 名字」、地块规划页已无驻军面板（建筑条目带「详情」）。
