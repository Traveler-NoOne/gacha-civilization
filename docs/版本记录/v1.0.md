# v1.0 · 初版

初版可玩 Demo 的基线状态。下列内容后来被 **v1.1 / v1.2** 更名、迁移或删除，**已不再存在于当前游戏里**，仅作归档与对照。

## 后来被 v1.1 更名 / 迁移的内容

- **图鉴的二级分类**（v1.0 的叫法）→ v1.1 更名为「**稀有度**」，并新增可与它并存的「**文明组**」分类。
- **图鉴里的「名词」分类** → v1.1 迁入新增的「**手册**」页（手册成为专有名词与世界观设定集）。
- **任务页左侧的六个功能按钮** → v1.0 用**几何多边形图标**（如正方形 = 「新建任务组」），v1.1 改为**文字按钮**。
- **卡组名**：v1.0 为 `原神组 / 崩坏组 / 绝区零组` → v1.1 随文明组更名为 `提瓦特 / 崩坏本征 / 绝区零`（`card_db.gd` 的 `GROUP_TO_CIV` 至今保留新旧两套写法，用于兼容旧存档）。

## 后来被 v1.2 删除的内容

- 一级页面里的「**休眠**」页（功能与其他页面重复，退出功能移到顶部栏「休眠 / 退出」）。
- 管理页的「**持有资源总览**」面板（顶部资源栏已显示）。
- 管理页的「**部落概况**」面板（幸福值 / 文化率 / 稳定度已显示在顶部栏）。
- 管理页独立的「**领地列表**」（并入地块详情区的下拉选择框）。
- 反馈页的 **github 行**。

> 这些删除项出现的版本是 v1.2，因此详细的"删除记录"也同步写在 [v1.2.md](./v1.2.md) 里；此处只作为"v1.0 曾有此物"的索引。
