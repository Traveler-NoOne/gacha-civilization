# v1.3 · 修复与后续 UI 调整

> 本版重点：修掉 v1.2 作弊功能的几个致命 bug；把管理页「指挥」区改成「中控区」+ 左中右三页签。

## 后续 UI 调整（v1.2 之后）

| 项目 | 调整内容 |
| --- | --- |
| 管理页「指挥」区 **改名「中控区」** | 标题由「指挥」改为「中控区」 |
| 指挥 / 军队 / 科技树 **由「上中下」改为「左中右」三个按钮切换** | 点击按钮切换中控区内容；每个页签独占整块高度、各自独立滚动，这样内容再多科技树也不会被挤出可视区域 |

## 本版修复的 Bug

| 问题 | 原因与修法 |
| --- | --- |
| 作弊功能「不能正常使用」 | **两个叠加的原因**：<br>① Godot 4.7 的 `CheckBox` 在 GL Compatibility 下**完全不绘制勾选框图标**（`has_theme_icon("checked")` 返回 true、图标也取得到，但屏幕上 0 个像素；只有文字画出来），玩家看不出勾没勾上 → 改用 `UIKit.toggle_checkbox()` 自绘（`[ ✔ ] 文字` + 高亮描边）。<br>② **作弊菜单比屏幕还高**：面板外沿到 y=749（视口只有 720），底部的「摧毁全部敌对单位」被挤到屏幕外、**根本点不到** → `DialogLayer` 增加 `fit_now()`：内容放好后测量真实内容高度，把弹窗高度夹在视口内，超出部分交给内部 ScrollContainer 滚动 |
| 勾选作弊后，一开始新游戏（或继续/读取）作弊按钮就消失、回到主菜单发现勾选被取消 | **根因：把作弊开关存进了 `GameState.state`，而它是「存档状态」**。`new_game()` 会重建整个 `state` 字典、读档会用存档里的 `state` 覆盖，所以开关每次都被重置回默认的 false。<br>**修法**：作弊开关与自动存档周期数本来就不属于某一份存档，而是玩家的全局偏好 —— 新增 Autoload `AppSettings`，把它们存到 `user://settings.cfg`，与存档彻底解耦；`GameState` 上的同名函数改成转发给它（调用方不用改）。读旧存档时顺手把残留的 `cheat_enabled` / `autosave_interval` 字段清掉 |
| 管理页中控区内容一多科技树就看不见 | 指挥 / 军队 / 科技树 由「上中下」堆叠改为「左中右」三页签切换；同时修掉一个隐藏 bug：`find_child()` 遍历不到被隐藏的页签，导致切换后内容拿不到容器而静默不刷新 —— 改为构建时持有成员引用 |

## 关键结论（供后续参考）

- 玩家的**全局偏好**（作弊开关、自动存档周期）必须放 `AppSettings`（`user://settings.cfg`），**不能**放 `GameState.state`（存档状态）。参见主 [README §已知的取舍](../../README.md#七已知的取舍)。
