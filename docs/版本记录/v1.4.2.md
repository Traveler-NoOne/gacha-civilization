# v1.4.2 · 移除硝石 + 资源图标接入 + 测试脚本加固

> 本版没有外部「更新指导」文件，内容来自开发过程中的讨论与决定（资源体系复盘 → 美术接入）。

## 1. 移除资源「硝石」

**原因**：硝石与其余具体资源不在一个量级。食物 / 木材 / 煤 / 铜 / 铁 / 原油都能命名一个时代（农业 / 青铜 / 铁器 / 工业 / 石油），硝石只能靠"火药"沾光，而**火药是制成品**（硫磺+硝石+木炭），硝石只是配方里的一味；它在文明 6 有位置，是因为文明 6 给**每个时代各配了一个战略资源**组成阶梯，硝石是其中一级。只搬那一级、不搬楼梯，它就是个孤儿。

期间考虑过两个替代方案，均未采纳：

- **换成「化学品」**：可行（与原油成对、抽卡解锁的高阶位很顺），但图标会与科研点的烧瓶撞车。
- **换成「炼金物」**（现实主义的早期化学副产物，炼丹/贤者之石的副产品）：风味最好，但会与「水晶碎屑」（元素宝石 / 崩坏核心 / 以太凝胶）抢同一个"精华"生态位；且**炼金本质是技术与知识，属于科技树而非物资**，留待 1.5 之后的长线内容。

**结论：没有代表性又找不到替身，就不该占一格——直接删。**

全链路移除：

| 位置 | 改动 |
| --- | --- |
| `scripts/data/constants.gd` | `RES_KEYS` / `RES_NAMES` / `CONCRETE_RESOURCES` / `CAPPED_CONCRETE` 去条目；`ADVANCED_RESOURCES` → `["iron", "oil"]` |
| `scripts/core/game_state.gd` | 初始资源表去掉 `niter` |
| `scripts/data/card_db.gd` | 删除材料卡「硝石粉」 |
| `scripts/ui/game_screen.gd` | 顶部资源栏去掉硝石（具体资源现为 8 项） |
| `scripts/ui/hex_map_view.gd` | 地图资源标记的 `_res_kind` / `_res_color` 去 niter |
| `scripts/core/world_gen.gd` | 头注释同步 |
| `tests/diag_v14.gd` | 资源栏期望清单同步 |

**兼容性**：道具页「资源明细」与存档迁移都由 `RES_KEYS` 驱动，自动跟着缩；`res()` / `add_res()` 用 `.get(key, 0.0)` 取值，旧存档里残留的 `niter` 键只是个**不会被读到的孤儿**，不会报错，也无需迁移代码。

**副作用（已知）**：`ADVANCED_RESOURCES` 同时被世界生成当「高级矿点池」用，所以**发展抽卡的高级资源地脉现在只会出铁 / 原油**（tier≥2 仍可出水晶碎屑）。将来想让矿点更丰富，应把「矿点池」从「高级分类」里拆成独立列表。

## 2. 资源图标（第一版，代码绘制）

用 `codeart2d` 技能**以代码绘制**（`art_source: code`，**没有使用任何图像模型**）出一套 13 个资源图标：生产力 / 科研点 / 行政点数 / 秩序结晶 / 凝聚力 / 人力 / 食物 / 木材 / 煤 / 铜矿 / 铁矿 / 原油 / 水晶碎屑。

- 源文件：`art/icons.resources.svg`（13 格 32×32，根 224×64）+ `art/icons-palette.json`（调色板类 `c-NAME`）。
- 渲染产物：`art/icons-4x/`（896×256）、`art/icons-1x/`（224×64），QA 全过（`resvg-py 0.5.0`）。
- 游戏用图：`art/icons/<key>.png`（128×128，按格切好）——**一个资源一张图，方便以后逐个替换**。
- **摩拉不在其中**：留空，规格见 `art/mora-icon-spec.md`（供临摹，注意只取"金色硬币"通用形态、中心纹样自创）。

接线（`UIKit.res_icon(key)` 统一取图，**找不到图就回退到原来的几何图形，删掉图标也不会崩**）：

| 位置 | 改动 |
| --- | --- |
| `scripts/ui/ui_kit.gd` | 新增 `res_icon(key)` + 缓存 + `RES_ICON_DIR` |
| `scripts/ui/game_screen.gd` | 顶部资源栏 chip 前加 15px 小图标（人力 chip 的 key 是 `pop`，映射到 `population.png`） |
| `scripts/ui/hex_map_view.gd` | 地图资源点由几何多边形改为图标（含"已耗尽"的压暗态） |
| `scripts/ui/views/view_world_page.gd` | 图例文案：改为「资源点图标：木材 / 煤 / 铜 / 铁 / 原油 / 水晶（与顶部资源栏同款图标）」 |

> ⚠️ 新增 PNG 需要 Godot 先做一次导入扫描（`godot --headless --import --path <项目>`，或打开一次编辑器），否则 `load()` 拿不到纹理。

## 3. 截图测试脚本加固（修 bug）

`tests/screenshot.gd` 调用的 `_open_tile_picker()` **在 v1.4 删「指挥」页签时被一起删掉了**（现对应物是 `_open_stronghold_picker()`）。脚本报 `SCRIPT ERROR: Nonexistent function` 后，`_ready()` 直接中断、**走不到 `quit()`**，于是窗口永远挂着——这就是"跑一半卡死"两次的根因（都停在 `16_dialog_recruit` 之后）。

修复：

- 过期方法名 → `_open_stronghold_picker()`，并加 `has_method()` 守卫，以后改名只会跳过该截图而不会中断。
- **新增看门狗**（`_arm_watchdog()`，120 秒）：任何一步卡住或报错，超时后强制退出并打印**最后完成的那张截图名**，不再把窗口挂着。
- `_shoot()` 记录 `_last_shot`，失败时可定位。
- 顺手删掉误名的旧图 `18_dialog_tile_picker.png`（新图为 `18_dialog_stronghold_picker.png`）。

修复后：完整跑完 34 张、约 17 秒、`stderr` 干净、正常退出。
