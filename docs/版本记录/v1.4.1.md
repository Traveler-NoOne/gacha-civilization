# v1.4.1 · 资源收支悬浮窗 + 占领按钮文案修正

> 来源：`抽卡文明 更新指导v1.4.1.txt`。原始需求正文附在文末。

## 需求与落地

| # | 需求 | 落地情况 |
| --- | --- | --- |
| 1 | 顶部资源栏中点击某项资源 → 基于点击位置弹出悬浮窗，列出该资源的收入 / 来源 / 维护明细 | ✅ 每个资源 chip 可点击，弹出悬浮窗（`GameState.resource_breakdown()` 提供明细）；点击任意处或 `Esc` 关闭 |
| 2 | 小 bug：世界系统 → 规划面板 → 地块规划页 → 「占领地块」按钮的消耗文案仍写「生产力」 | ✅ 改为「行政点数」 |

## 明细内容

悬浮窗按「收入 / 支出」分段列出：
- **收入**：建筑产出、领地（生产力）、周期结算（秩序结晶 / 凝聚力 / 行政点数及其 buff 与收支项）。
- **支出**：建筑维护（生产力）、人口维护（食物）。
- 末尾给出**净收支 / 周期**；人力则显示住房上限 / 已指派 / 空闲。

## 改动文件

- `scripts/core/game_state.gd`：新增 `resource_breakdown(key)`。
- `scripts/ui/game_screen.gd`：资源 chip 点击 → `_show_res_info()` 悬浮窗（`_res_popup`）；`Esc` / 点击空白关闭。
- `scripts/ui/views/view_world_page.gd`：占领按钮文案「生产力」→「行政点数」。
- 测试：新增 `tests/diag_v141.*`。

## 附：原始需求（`抽卡文明 更新指导v1.4.1.txt` 正文，原文照录）

为了方便玩家搞懂资源的收支，顶部资源栏中，对于某项资源玩家点击后会弹出一个基于点击位置和对应资源的悬浮窗，统一列出资源的收入和来源。
例如：
建筑+资源数
人口+资源数
——
人口维护-资源数
建筑维护-资源数
之类的。

小bug:
1.世界系统中，规划面板中，地块规划页内，占领地块按钮显示的消耗仍然是生产力，而非行政点数。
