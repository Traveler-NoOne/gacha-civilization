# v1.7.2 · 默认进世界 + 人力管理收敛 + 据点名缩放（首个发布版）

> **本版是 v1.8 大世界重写之前的收尾小版本，也是接入 git 后第一个「编译打包」的发布版**（Windows 单文件 exe）。
> 三项改动都不大，但都来自实际试玩体验；落地过程中顺带修掉 v1.7.2-1 引入的一个真 bug。
> 本版**没有单独的更新指导文档**，改动直接落在提交 `v1.7.2-1` / `v1.7.2-2` / `v1.7.2-3`。

## 一、默认进入世界系统（v1.7.2-1）

- 进游戏后的默认视图从「管理」改为「**世界**」——操作都发生在大世界上，管理页不再是主入口。
- 默认视图收进常量 `DEFAULT_VIEW := "world"`，不再散落硬编码。

**顺带修掉的真 bug（本版最值得记的一处）**：这次改动把**常量名写进了引号**——

```gdscript
var current_view := "DEFAULT_VIEW"   # 错：这是字符串字面量，不是常量
_switch_view("DEFAULT_VIEW")         # 错：VIEWS 里根本没有这个 id
```

`_switch_view` 找不到 id 时会**静默 `return`**（`view_host` 初始也没有任何子视图），于是：

- **开局不显示任何视图**，内容区一片空白；
- 底栏所有按钮都不高亮（`_refresh_nav` 拿 `current_view` 对不上任何一个 id）；
- 玩家必须**手动点一次视图按钮**才恢复正常。

> **教训：常量名一带引号就退化成普通字符串，编译器不会报错。**
> 而 `"DEFAULT_VIEW"` 恰好不是一个合法视图 id，正中 `_switch_view` 的静默兜底分支 —— 两个"看起来没问题"的错误叠加，结果既没有报错、也没有崩溃，只有"看着不对"。
> 已改为 `var current_view := DEFAULT_VIEW` / `_switch_view(DEFAULT_VIEW)`。

## 二、人力管理只列「需要人力」的建筑（v1.7.2-2）

- `view_manage_page._refresh_labor()` 原来对每个已建建筑都出一行，`max_workers(level) <= 0` 的（比如经典仓储）会显示成一行「无需人力」的占位。
- 改为**直接跳过** `max_workers <= 0` 的建筑，列表只留真正要派人手的。
- 判定顺序一并调整：**先算 `maxw` → `maxw <= 0` 就 `continue` → 再置 `any = true`**（原来的顺序会先置 `any`，空列表也可能被误判成"有内容"）。
- 顺带：删掉误提交进仓库的 `ok` 文件（v1.7.2-1 提交时手滑带进去的 33 行），并补上 `view_manage_page.gd` 缺失的文件末尾换行。

## 三、地图只给据点中心画名字 + 长名字自动缩字号（v1.7.2-3）

- 原来**每个我方地块都画据点名**，相邻格子会互相盖住、糊成一片。
- 改为只给**据点中心**（`is_capital` 或坐标 == `capital`）画名字。
- 长名字会**自动缩字号**：起始字号 `hex_size * 0.30`（夹在 9~14），逐 1 号往下缩，直到宽度塞进 `hex_size * 2.6`，最小 9 号。

## 四、首个发布版（编译打包）

- **版本号补齐**：`Consts.DEMO_VERSION` / `DEMO_VERSION_FULL` 从 **v1.7** → **v1.7.2**（这笔账自 v1.7.1 就欠着；`diag_v17` 的第 8 条护栏只校验「`_FULL` 包含 `_VERSION`」，所以升级是安全的）。
- **打包形态**：Windows **单文件 exe**（`binary_format/embed_pck=true`，PCK 内嵌，双击即玩，可随意改名 / 移动）。
- **导出元数据**：产品名「抽卡文明」、文件 / 产品版本 `1.7.2.0`、描述取 `DEMO_VERSION_FULL`、版权为免责声明；图标暂用 `res://icon.svg`。
- **随包附 `说明.txt`**（玩法 / 操作 / 免责声明）。
- 发布产物放在 `dist/`（该目录不入库）。
