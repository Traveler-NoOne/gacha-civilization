## 版本脉络

- **v1.0**：初版可玩 Demo。五 / 六个一级页面、图鉴「名词」分类、任务页多边形图标按钮、管理页的持有资源总览与部落概况、反馈页的 github 行等。
- **v1.1**：单位与战斗系统重构；图鉴新增「文明组」二级分类、原「二级分类」更名「稀有度」；日志新增「手册」页（「名词」从图鉴迁入）；任务页按钮改文字、新增「归档」。
- **v1.2**：新增自动存档周期、作弊功能；管理页减负（删持有资源总览、删部落概况、领地列表并入地块详情）；删除「休眠」页；修复至宝角色页单位列表点不中的 bug。
- **v1.3**：作弊相关 bug 修复（CheckBox 自绘、弹窗自适应高度、开关移到全局 `AppSettings`）；中控区由「上中下」改为「左中右」三页签。
- **v1.3.1**：据点与地块解耦（据点含多个地块，本作单据点、保留切换入口）；建筑系统迁到世界页「规划面板（信息页 / 地块规划页）」；地块**可用土地**计容（建筑 0.3~0.6、同种可重复）；**规划队列** + 生产力盈余上限 20；扩张改用新增的**行政点数**（含收支 buff/debuff 与行政影响力）；据点**掌控力**预留。
- **v1.4**：删除管理页「指挥」页签（扩张归世界页）；据点详情补回「人力管理」（规划队列左侧、只列已建建筑）；可用土地 UI 改「已用 / 上限」；顶部资源栏分**抽象 / 具体**两组各两行、具体资源全显；新增**存储上限**（生产力 20 / 科研 200 / 具体资源 100）与建筑「经典仓储」。
- **v1.4.1**：顶部资源栏支持**点击资源弹出收支悬浮窗**（列出建筑产出 / 领地 / 周期结算与建筑维护 / 人口维护等，含净收支）；修正世界页「占领地块」按钮文案（生产力 → 行政点数）。
- **v1.4.2**：**移除资源「硝石」**（与食物/木材/煤/铜/铁/原油不在一个量级，又找不到替身；「炼金」作为技术知识归科技树，留待长线）；首个**资源图标集**（codeart2d 代码绘制、13 个）接入顶部资源栏与地图资源点，摩拉留白待临摹；修复截图脚本的过期方法名并新增**看门狗**（超时或中途报错强制退出，不再挂死窗口）。
- **v1.5**：**抽卡 → 攫取系统**（召唤 / 打捞 / 发展三个子系统，含各自的世界观与命名）；敌方映射按新设定对调（召唤→敌意个体、打捞→虚空据点）；新增**客人 / 公民**双状态（客人可**招募**为公民——需在世界选地部署——或**遣返**，超 15 周期有概率离去）；单位开始**吃维护费**（驻守我方领地 −60%、领地外 −10%）、有**血量/移动力**，世界系统支持**点击轮换选中**、**移动**与**攻击**（接上 `simulate_battle` 的单位级结算）；免责声明进游戏（主菜单左下角 + 反馈弹窗）。
- **v1.6**：**背景重设**——舞台改为**漂浮在量子之海中的一枚世界泡**，虚拟词"虚空 / 最近的世界"换成**量子之海 / 邻近世界泡**，抽的是**濒临末日世界泡**里的存在（所以多数愿意留下），彻底拆掉拐卖感；**攫取 → 世界泡**（一级按钮与系统名）；**全局字体换黑体**（项目级主题 + SystemFont，删掉默认字体回退链猜出来的花哨字）；**开局赠送 5★ 公民「格蕾修」**（前文明方舟计划的乘员，主题锚点），并进卡池；地块规划页**点建筑条目看完整效果**、**未满足科技的建筑自动隐藏**；修掉「修建后进管理页，人力管理与规划队列仍是空的」——根因是**缓存视图切回不刷新**。
- **v1.6.1**：**驻军功能从"地块规划页"搬到"单位操作窗"**，成为「攻击 / 移动」之后的第三个按钮（驻军 = 维护费打折 −60%/−10%，但不能移动与攻击）；修掉**单位在领地外（无主地块）不显示**的 bug；**操作窗补上单位立绘**（顺手把底部队列也改成真正的「立绘 + 名字」窗口）。
- **v1.6.2**：**单位移动点亮周围迷雾**；**摩拉 → 货币**（资源键 `mora`→`currency`，旧档余额自动迁移；摩拉将来作为另一种高级资源回归）；新增 **古典方孔钱**货币图标（codeart2d，第 14 格）；新增建筑 **经典市场**；**全建筑数值平衡**——先修结构性问题（每级维护 0.5→0.25，并强制"每级加成 > 维护费"，否则升级是负收益），再把磨坊改成食物放大器、学院/黑土学院拉到 2 人力、高阶建筑成本降到能真的建起来。
- **v1.7**：**整体优化（不新增玩法）**——4 个真 bug（管理页收支与真实结算/悬浮窗三套口径、移动高亮会给出走不过去的格子、自动存档默认值自相矛盾、游戏内版本号停在 v1.5）；**死代码清理**（19 个零调用方函数 + 19 个死常量 + 2 个死信号 + 3 处死数据，MCP `signal_map` 参与）；**旧档兼容按决定删除**（1.0 不做兼容，改为**存档版本校验**）；**12 处去冗余**（击杀清剿 4 份拷贝抽 `clear_enemy_tile()`、敌人命名 5 套收成 `ENEMY_LABELS` 词表、维护费汇总/地块 key/`_fmt`/`_game_screen` 等）；文件清理与 README 对齐；新增 **`diag_v17` 护栏**（8 条：收支同源 / 高亮即可达 / 资源↔图标 / 职业映射 / 卡组一致 / 每级加成 > 维护费 / 无死常量 / 版本一致）。
- **v1.7.1**：**立绘重裁**（旧裁剪因"取景框长宽比与目标不一致"被程序切掉了头顶和蝴蝶发饰；改为用户手裁 190×170 / 60×60 / 28×28）；**底栏改三段式**——结束周期在左、**球形「世界」按钮落在整条栏的几何正中**、四个视图按钮在右（居中靠"左右两区同时 `SIZE_EXPAND_FILL`"实现）；**`Art` 抽象**把 `art/icons/` 与 `art/ui/` 两条取图路径合并成一条 `get_icon(name, type)` 并删除旧 `res_icon()`；**确定美术风格为低多边形**（不要平滑 / 要锐边 / 直线 / 低面数）；世界系统**点选逻辑按优先级搁置**（设计与拆解已存档，随时可捡起）。
