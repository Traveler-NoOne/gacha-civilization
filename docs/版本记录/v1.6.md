# v1.6 · 量子之海与世界泡（背景重设）

> 来源：`抽卡文明 更新指导v1.6.docx`（云盘）。
> 背景依据：米哈游《崩坏3》官方设定——**虚数之树**孕育无限世界（枝干=文明形态、叶片=时间线上的现实存在），**量子之海**由「以太」构成、经「涨落」成膜并演化为**世界泡**，是容纳所有世界泡的「海洋」；树能创造造物、海不能，只能**吞噬**。

## 为什么重设

原设定"召唤来自**最近的世界**的存在"带着**拐卖人口**的味道。v1.6 把舞台改成**漂浮在量子之海中的一枚世界泡**，于是抽的不再是"从活得好好的平行世界抓人"，而是**从濒临末日的邻近世界泡里捞存在与遗物**——**他们本来就待不下去了，所以大部分直接接受招募**。是收留，不是拐骗。

---

## 1. 设定与文案重写

- **虚空 → 量子之海**：打捞是从量子之海汲取混沌物质（以太涨落凝结），取出并凝结后才知道捞到了什么。
- **"相对最近的世界" → "相对最近的世界泡"**；召唤是从**邻近世界泡**呼唤存在。
- **发展 = 把一整片世界泡包裹进来**（所以凭空多出大型矿脉，也几乎必然把泡里的敌人一起包进来）。
- 召唤规则里补上核心那句：**"附近的世界泡大多已濒临末日，所以受召唤者往往愿意留下——留下，比回去强。"**
- 手册新增词条：**量子之海**、**世界泡**。
- **敌人 / 据点改回通用称呼**：`敌意个体 → 游荡敌人`、`虚空据点 → 高危据点`（以后的设定细分时再动，通用称呼不绑世界观）。

## 3. 字体：全局换黑体（删掉那个花哨字体）

**诊断**：项目里**没有任何字体文件**，`project.godot` 也没挂主题——UI 一直在用 **Godot 内置默认字体（Open Sans）**，中文靠**系统回退链**猜，`[b]` 粗体还会再走一套。小字号下猜出来的那个字就是"花里胡哨"的来源（不是刻意选的）。

**改法**：新增**项目级主题** `scripts/ui/ui_theme.tres`，挂在 `project.godot` 的 `gui/theme/custom`：
- `default_font` = `SystemFont`（黑体族：微软雅黑 / SimHei / Noto Sans SC…，weight 400）
- `RichTextLabel` 的 `normal_font` / `bold_font` 分别钉在同一族的 400 / 700 —— **`[b]` 不再走另一套字体**

用 `SystemFont` 读系统字体，**不打包任何字体文件**，因此也没有字体授权问题。

> ⚠️ 踩过的坑：第一版把字体设在 `main.gd` 的 `_ready()` 里，结果**截图脚本不经过 main.gd**，看不到效果（规则面板仍是花哨字体）。改成**项目级主题**后游戏与测试都会吃到。

## 4. 开局赠送 5★ 公民「格蕾修」

- `new_game()` 创建：**格蕾修**，5★、**投射者**、英雄位阶、**公民**、自动落在首都、移动力已充满。
- 数值（按现有 5★ 基准）：`atk 62 / def 22 / hp 230 / spd 4 / agi 26` = **攻中等 / 防低 / 血低 / 速中等 / 敏高**（`card_db` 的 `char_grieso` 与之一致，**同时进卡池**）。
- **为什么是她**：格蕾修是前文明纪元「逐火之蛾」的**十三英桀之一**（刻印「繁星」），也是**方舟计划**的乘员——方舟携带前文明全部科技成果离开太阳系、去寻找新的世界，后来失联。**她本身就是"从毁灭世界漂来的遗民"**，正是本作核心设定（这枚世界泡靠收留末日来客立起来）的具象化，也是召唤 / 招募系统的预告：她是第一位"客人"，只是开局就已经是公民了。

## 5. 地块规划页：建筑详情 + 科技门槛隐藏

- **点建筑条目**（或条目里的「详情」按钮）展开该建筑的**完整效果**——直接复用现成的 `BuildingDef.summary()`（描述 / 人力上限 / 每人产出 / 每级加成 / 幸福度 / 消耗与升级），**不打断修建与入队**。
- **未满足科技条件的建筑自动隐藏**（`def.required_tech` 未解锁即跳过），不再显示成灰条目。

## 6. 修复：管理页「人力管理 / 规划队列」切回来是空的

**根因**（`game_screen.gd:166 _switch_view`）：视图**已缓存**时只做 `show_view` + `_refresh_nav()`，**从不调用 `refresh()`**。所以管理页停留在"创建时"的空状态；修建建筑后再切过去看到的还是旧的空列表，必须手动点一次「据点」弹窗才触发刷新。**这个 bug 其实影响所有缓存切回的页面**。

**修法**：切回缓存视图后，若该视图有 `refresh()` 就调一次。
