# v1.5 · 召唤系统与客人公民（兵棋与探索）

> 来源：`抽卡文明 更新指导v1.5.docx`（云盘）。这是对**世界系统的一次重大更新**。

## 版本目标

把「抽卡」重做成有世界观的**攫取系统**（召唤 / 打捞 / 发展三个子系统）；召唤来的角色以**客人**身份进入至宝，可**招募**为公民（需在世界选地部署）或**遣返**；单位从此**吃维护费、能移动、能攻击**——世界从"看地图"变成"下棋"。

---

## 1. 术语与文案（含母题）

**母题**：三个子系统的名字是这个文明对自己行为的**美化**；一级按钮「**攫取**」才是本质（这些行为本质上都极其冒进）。

| 位置 | 原 | 现 |
| --- | --- | --- |
| 一级按钮 | 抽卡 | **攫取** |
| 池页标题 | 抽卡 | **召唤系统 / 打捞系统 / 发展系统**（按池切换） |
| 池页签 | 轮换 / 资源 / 发展 | **召唤 / 打捞 / 发展** |
| 动作按钮 | 抽 1 次 / 抽 10 次 | 召唤 1 次 / 10 次、打捞 1 次 / 10 次；**发展只有 1 个「创造」** |
| 结果标题 | 本次抽卡结果 / 抽卡结果（轮换） | 本次**召唤**结果 / **召唤结果**（按池取词） |
| 状态与空态 | 当前可以抽卡 / 还没有抽卡记录 | 当前可以**攫取** / 还没有**攫取**记录 |
| 跨页引用 | 去「抽卡 → 轮换」抽角色 | 去「**攫取 → 召唤系统**」**召唤**角色 |
| 手册分类 | 抽卡与经济 | **攫取与经济** |
| 成就 | 初次抽卡 | 初次**召唤** |
| 作品名 | 抽卡文明 | **不变**（`Gacha` 类名 / `"gacha"` 视图 id / 存档魔数也不动） |

**每个子系统的世界观文案**（`gacha_view.gd` 的规则面板）：世界在虚空中移动、当前卡组即最近的世界；`打捞`从虚空汲取混沌物质、取出才知道是什么，因此更容易被盯上；`发展`直接把虚空一角包进来。

## 2. 敌人映射按新设定对调（机制变更）

| 子系统 | 原 | 现 |
| --- | --- | --- |
| 召唤 | 危险据点 | **敌意个体**（概率性；90 次保底出高危敌意个体） |
| 打捞 | 游荡敌人 | **虚空据点**（次数越多概率越高；10 次保底出极度虚空据点） |
| 发展 | 终极威胁 | **不变（必然）**——"几乎百分百"只是措辞 |

⚠️ **这是本版最大的难度变化**：据点比游荡敌人强，且 `evolve()` 里据点会**每周期持续生兵**，而对调后是**抽得最频繁的打捞池开始招据点**。要回收就调 `HAZARD_BASE_CHANCE` / `HAZARD_FORCE`。

## 3. 客人 / 公民

**数据**：单位新增 `status`（guest/citizen）、`acquired_cycle`、`leave_chance`、`hp`、`move_left`。
- 召唤来的角色 → **客人**；本土征兵 → **公民**。
- 旧存档：`unit_type=="character"` 且无 status 的按客人补齐，其余按公民。

**规则落地**
- 客人：每周期 **+0.1 凝聚力**、**−0.1 食物**；**超过 15 个周期**未招募后，每周期离去概率自增 **0.1%~1.0%**（随机），触发即离去。
- 公民：**必须存在于大世界**（征兵改为自动派驻首都，首都满 4 人则拒绝征兵）。
- **单位维护费**：每周期 食物 0.5 + 摩拉 3.0；**驻守我方领地 ×0.4（−60%）**、**领地外 ×0.9（−10%）**；写入 `report`、`resource_breakdown`（新增摩拉支出分支）与 `_balance_lines`。
- 移动力：**2 移动速度 = 1 移动力**（用基础速度，不吃位阶/等级倍率），每周期重置。

**至宝 → 角色子系统**：三区正名为 **单位列表 / 状态窗口 / 管理窗口**；单位列表新增**二类筛选（全部 / 客人 / 公民）**；状态窗口显示**客人·公民徽记**，客人时底部出现 **「招募」「遣返」** 两个按钮（公民无按钮）。

## 4. 招募流程（严格按你定的规则）

1. 状态窗口点「招募」→ `begin_recruit` 记下 `state["pending_recruit"]`，跳到世界系统
2. 世界页进入**选地模式**：高亮可部署地块（我方领地 + 掌控力 ≥ 80% + 未驻满）
3. 点**满 4 人**的地块 → 提示「该地块已驻满，请另选」，**保持待选**
4. **只有点「确认招募」→ `confirm_recruit()` 才真正转换**（客人 → 公民 + 落地）
5. **未选地 / 点取消 / 离开世界页 / 按 Esc → 取消招募**，客人保持客人（与"遣返"无关）
6. 「遣返」→ `dismiss_guest()` 直接从库存移除（送回他自己的世界）；公民不可遣返

## 5. 世界系统：单位操作

- **点击格 = 确定性优先级 + 同格重复点击轮换**：第一次点选权重最高的内容，再点同一格依次选下一档，选完归零；**换一格则从头**。
  顺序（权重降序）：**市中心(1000) → 该格每个公民单位各一档(800) → 地块(500)**。
- 一格 **≥2 个公民单位**时，世界页底部弹**立绘条**，可直接点选单位。
- **单位操作窗**（世界页左下角浮层）：左侧立绘，右上 **攻击力 / 血量 / 移动力**，右下 **「攻击」「移动」**；移动力耗尽时两个按钮禁用。
- **移动**：绿色高亮合法目标；相邻格耗 1、间隔一格耗 2（中间格须可通行、目标未驻满）。
- **攻击**：红色高亮相邻敌方地块；以 `UnitDB.resolve_damage` 结算（含克制），**扣地块 `force`**（持久化，归零即清剿 + 给经验）；敌人反击扣单位 `hp`，`hp` 归零则**阵亡**（移除 + 触发 v1.3.1 预留的 `on_unit_died` 行政 debuff）。攻击耗尽本周期行动。
- 掌控力：`tile_control()` / `control_ok()` 已接进部署校验，但据点 `control` 仍恒 1.0 → **门槛先挂着、暂不拦人**（按你的决定）。
