### 1.3 生成契约（管线）

```
① 死地图（原型图，"原本的完整地球"）   DEAD_SCALE=4.0，气候栅格 FIELD_GRID≈160~384
     层：高程(板块/造山带) · 气候(12 月温/降水/柯本) · 汇流与河道
                 ↓
② 六边形裁切窗（硬指标=水陆比 25%~75%，取最接近 50:50）
                 ↓
③ 采样成地块（面积平均 + 水陆配额 + 干湿三档配额 + 冷热三档配额，全部"排名+两头分配"）
                 ↓
   tiles（terrain/cover）+ edges（river_edge / water_edge）
```

约束（松绑后）：**不要求逐格纯函数，但要求整图可复现**（同 seed + 同尺寸 + 同版本 → 逐位一致；并列一律按坐标兜底）。

## 五、许可红线与正确做法

1. **MIT（本项目）× 任何许可**：
   - 可**放心移植**：MIT（worldengine / mewo2 / Azgaar / whitebox / landlab / dandrino / SebLague / OpenCiv3 / godot-gdhexgrid）。
   - 需**保留版权声明**：把来源与许可记进 `README` 第八节（现有做法照旧）。
2. **GPL-3.0 / LGPL-3.0（richdem / fastscapelib / plate-tectonics）**：**代码一行都不进**。
   - 合法且够用的替代：**读论文/文档，用自己的话与自己的结构重写**（版权保护"表达"，不保护"算法与思想"）。
3. **MPL-2.0（Unciv）**：可与 MIT 代码构成 Larger Work，但**被修改/翻译的 MPL 文件本身仍须 MPL**。
   → 对本项目（想保持纯 MIT）最稳的做法：**只借鉴算法、参数与文件职责划分，独立实现**；不要逐行翻译 `.kt`。
4. **无许可仓库**：默认"保留所有权利" → **只看思路，不复制代码/数据/素材**。
5. **图形素材**：无论许可如何，一律不用（沿用"美术自产"原则）。
6. **不引入运行时依赖**：GDScript 不能直接调 Python/Rust/C++ → **一切"移植"= 用 GDScript 重写**；控制流与数值公式可照抄（MIT 项）。

## 六、移植时必须守住的三条本项目约束

1. **确定性**：生成器内**不许有未定种随机**；并列一律**按坐标兜底**；遍历顺序固定（总纲 3.4）。
   - 注意：跨平台浮点（`sin/cos/sqrt`）在极端情况下可能有末位差异 → 别把"逐位一致"建立在对超越函数的强依赖上。
2. **平面而非球面**：外部实现多为**行星/球面**（worldengine 尤其）→ 只取"局部块"的算法，纬度带按本项目"世界自己算"或"死地图绝对纬度"的口径（W5 已定，别混）。
3. **观感只按真实感调参**：总规则第 8 条 —— 抄来的阈值只允许为"像真的"而改，不为"海太多/山太少"而改。

## 七、建议的最小验证动作（想试的时候再做）

1. **只做一件事**：把 `priority-flood 填洼 + D8 流向 + 汇流累积` 用 GDScript 写成一个**纯函数模块**（输入高程网格 + 海洋掩膜，输出 `flow_accum`/`flow_dir`），配一个 headless 断言场景（对照径流守恒：除入海口外，每格 `accum == 1 + Σ上游`）。
   → 这是 S5 真正卡住的那一步，做完"连续水系"就能自然成型。
2. 若要做"雨影修正"：先按 W5 已定的三步顺序（修尺度 → 校准毫米标尺 → 软钳 + 局部归一化），**再**对照 Azgaar 的风带参数。
3. 若要做"群岛/大陆"：先只做**连通块统计**，把它当作 `pick_crop` 的第 3 层打分，不动生成器。

## 八、一句话结论

- **最能"套用"的两个**：[mewo2/terrain](https://github.com/mewo2/terrain)（短、MIT、无依赖，S1/S2/S5 的算法蓝本）与 [Azgaar](https://github.com/Azgaar/Fantasy-Map-Generator) 的**降水/河流两块**（MIT）。
- **最该通读的一个**：[worldengine](https://github.com/Mindwerks/worldengine)（MIT，模块划分与我们的管线一一对应）。
- **同引擎工程参考**：[OpenCiv3](https://github.com/C7-Game/OpenCiv3)（MIT，Godot + C#）。
- **4X 玩法规则参考**：[Unciv](https://github.com/yairm210/Unciv)（MPL-2.0，**只看不译**）。
- **S5 河流的算法权威**：[whitebox-tools](https://github.com/jblindsay/whitebox-tools) / [landlab](https://github.com/landlab/landlab)（均 MIT）。
- **绝不能用代码的**：richdem、fastscapelib（GPL-3.0）、plate-tectonics（LGPL-3.0）、无许可仓库。
