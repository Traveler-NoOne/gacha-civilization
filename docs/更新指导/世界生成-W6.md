# 世界生成 · W6 —— 新游戏设置（卡池组 / 地图类型 / 质量档）

> 状态：⬜ 未开始（用户将统一审阅）
> 依赖：W5
> 总纲：[世界生成-过程模拟.md](./世界生成-过程模拟.md)（第九节 W6）

## 一、目标

**开局让玩家选。** 现在新游戏是"一键开始"，这一段把它变成"一小页设置"。

## 二、做什么

| # | 设置项 | 选项 | 影响 |
| --- | --- | --- | --- |
| 1 | **卡池组** | 全部（默认）／只提瓦特／只崩坏本征／只绝区零／自定义多选 | 影响**能抽到哪些卡**（`card_db` 的文明组过滤） |
| 2 | **初始地图类型** | 大陆（默认）／群岛／不在乎 | 走 W5 裁切器的**第 3 层形态判据** |
| 3 | **生成质量档** | 低（256）／中（512，默认）／高（1024） | 死地图分辨率 → 生成时间与地形细节 |
| 4 | （可选）**世界年龄** | 早期 / 晚期 / 随机 | 直接给 `world_age`（侵蚀轮次）——影响"山多还是平原多" |
| 5 | （可选）**种子输入** | 留空 = 随机；填了 = 复现指定世界 | 方便玩家分享、也方便自查 bug |

> ⚠️ **质量档必须写进存档**（用户 2026-10-13 已定）：
> 否则玩家选了"高"、读档时按默认"中"重做 → **同一局的地图会变样**（不只是变糊）。

## 三、验收

1. 新游戏能选；**选完真的生效**（例如选"群岛"，裁出来的图就明显是群岛）。
2. **读档后与生成时一致**（尤其质量档：在同一档下重做，地形逐位一致）。
3. **默认值**要定好：不选也能直接开局（默认 = 全部卡池 + 大陆 + 中档）。
4. 4 个无头自检全绿；设置项的界面**观感交用户手测**。

## 四、范围外

- **不做"多卡池组混抽的权重调节"**（那是抽卡系统的事，另开）。
- **不做难度设置**（本作明确**不做动态难度**，见 README 设计理念）。
- **不做"高级/自定义生成参数"**（板块数、侵蚀轮次那些 —— 留给开发者自用，不给玩家）。

## 五、风险

- 卡池组过滤**会牵到抽卡/图鉴/保底**几处（不止生成器）→ 如果发现牵连太多，
  **允许把这一项拆出去单独成段**（W6 先只做"地图类型 + 质量档"，卡池组另立 W6b）。
