# 世界生成 · W7 —— 拼接新世界（玩法结构改动）

> 状态：⬜ 未开始（用户将统一审阅）
> 依赖：W6
> 总纲：[世界生成-过程模拟.md](./世界生成-过程模拟.md)（第八节全节）

## 一、目标

**废弃"扩张"，改由发展卡池给一整个世界。** 抽到之后，在现有地图的**六个方向之一**
拼上一块**同样大小**的新世界；终极威胁可以**存在并活动**在新世界里。

## 二、做什么

### 2.1 生成与拼接

| # | 内容 |
| --- | --- |
| 1 | 发展卡池 → 不再只给范式树，而是**给一整个世界** |
| 2 | 新世界的**初始参数与现有世界不同**（尤其 `world_age`：有的是早期世界、有的是晚期世界 —— 用户 2026-10-13 指出）→ **每块世界各存一份配方**（W1 的 `state["worlds"]` 已备好） |
| 3 | 从**六个方向随机选一个**（用已定种的 RNG）→ 算出该块的 `origin`（**全局轴向坐标的平移量**） |
| 4 | 新世界按同一套流程生成（W2~W5）→ 采样成地块 → **按 `origin` 平移**写进 `state["tiles"]`（键是全局坐标，**结构不变**） |
| 5 | **接缝**：做**过渡带**（用户已选）→ 建议做成"**裂隙 / 虚无 / 混沌区**"地形，**既是天险、也是敌人的入口** |

### 2.2 显示与切换（**用户 2026-10-13 定的方案**）

- **一次只显示一个世界**；
- 某个方向上**存在**世界 → 那个方向显示一个**三角形方向按键**；
- 点击 → **渲染上销毁当前世界、渲染新的世界**（⚠️ **内存上不销毁**）；
- **所有功能只作用于"当前显示的世界"。**

### 2.3 跨界移动

- 边界外默认是**空白**；
- 单位本回合**够得着**边界外时 → 在边界外显示一个**虚拟高亮格**：
  - **那个方向有世界** → **实心高亮**（能过去）；移过去 = **直接送到对应的全局坐标那一格**（因为是平移拼接，**查"坐标属于哪块"就是加减法**，不必维护对应表）；
  - **没有世界** → **虚线 / 半透明**（不能过去，提示"那边是量子之海"）。

### 2.4 全局量（用户 2026-10-13 定）

| 项 | 决定 |
| --- | --- |
| **稳定度**等全局量 | **全局统计**（所有世界加总），避免"拼一块新世界 → 稳定度突变" |
| **敌人生成上限** | 按**全局空余地块** |
| **敌人计数** | 做成**全局变量增量维护**（死了减一、生成加一，不必每次枚举全图）；**只允许单一入口修改**；⚠️ **不加自检断言**（用户明说省 token，漂移他自己抓） |
| **威胁跨界** | ✅ **可以**通过接缝走进玩家的老家 → 需要**通知**玩家（日志/弹窗："终极威胁进入了 XX 世界"） |

## 三、验收

1. 抽到发展卡池 → 地图上**真的多出一块世界**；能通过方向键**切过去看**。
2. **跨界移动能走通**（虚拟格 → 送到对应世界的那一格）；没世界的方向**走不过去**且有明确提示。
3. **威胁能跨界**，且玩家会收到通知。
4. **全局量正确**：拼了新世界后，稳定度/敌人上限**按全局**计算（不会突变）。
5. 4 个无头自检全绿；观感交用户手测。

## 四、范围外

- **不做"世界地图"（只读鸟瞰图）** → 单独成 **W8**。
- **不做世界之间的人口/资源搬运规则**（如果玩家能跨世界走，那"人/资源能不能跨"是**新玩法问题** ——
  如果 W7 做到一半发现必须回答，**停下来问用户**，不要自己定）。
- **不做"旧世界的世界泡自毁/末日"**这类新机制。

## 五、风险

- 这是**玩法结构改动**（不是纯生成器）：它动到绘制、寻路、相机、稳定度、敌人生成 ——
  **但用户选的"一次只显示一个世界"方案已经把工作量压下来了**（总纲 8.1：那几处"假定地图只有一块"的地方基本不用改）。
- ⚠️ **存档会随世界块数线性增长**（每块 ≈ 1387 格）—— 用户已明确接受（"本来就是大体量游戏"）。
- ⚠️ **接缝是观感最容易崩的地方**（两套气候硬接）→ 过渡带要**先出一版图给用户看**再定。
