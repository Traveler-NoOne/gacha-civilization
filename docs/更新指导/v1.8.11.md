# v1.8.11 统计面板（追加段）

> 状态：⬜ 未开始（排期在 v1.8.10 之后）
> 来历：v1.8.7 要删掉「管理」入口，而**部队统计**是那里唯一没分到新家的功能。现决定为它单独立一个面板。

## 一、为什么不能塞进「据点管理窗口」

- **部队统计的本质是"整个大世界"的口径**：大世界上有多少单位、多少编队 —— 它不隶属于任何一个据点。
- **据点管理窗口将来要通用**：多据点玩法时，同一个面板会被每个据点各开一份。把一个"全世界"的数字塞进去，要么每个据点都重复显示一遍，要么就变成"只有首都能看"的怪东西。

→ 结论：**单独立一个「统计面板」**。

## 二、面板定位

**"能统计、但一时不知道该放哪"的东西的收容所。**

第一批内容（用户原话：能统计的都可以先放这边）：

1. **所有资源** —— 食物 / 货币 / 木材 / 煤 / 铜 / 铁矿 / 原油 / 水晶碎屑 / 科研点 / 行政点数 / 秩序结晶 / 凝聚力 …
2. **所有单位** —— 总数、按类型 / 据点 / 等级分组；以及**编队数**（用户明确：部队统计 = 有多少单位 + 多少编队）
3. **所有持有的地块** —— 总数、按地形 / 资源点分组
4. **领地** —— 我方领地 / 敌方据点 / 无主，含各自的掌控力与土地口径

## 三、位置与交互

- **位置：资源栏的中间**（顶部资源栏中段那块空着的地方）。
- **切换统计类型的按钮放在面板左侧**（竖排一列）。
- 内容区显示当前类型的统计。

## 完成记录（v1.8.11）

### 开工前把待定项一次定掉（免得再卡住）

| 待定项 | 定案 | 理由 |
| --- | --- | --- |
| **形态** | **点开式**：资源栏中间「统计」入口 → 在它下面展开面板 | 资源栏只有 99px，塞不下"所有资源"这种列表；项目里已有同款先例（点资源弹收支悬浮窗） |
| **默认类型** | **资源** | 用户定：*"统计一般最基础的就是看经济。"* |
| **类型切换** | 面板**左侧**竖排一列 | 用户定的 |
| **单位 / 编队** | 同一类（单位）里分两段 | 它们本来就是一起看的（部队统计 = 多少单位 + 多少编队） |
| **数字口径** | **全部复用已有单一来源** | 项目铁的规矩（两处口径迟早会对不上） |

### 做了什么

- **新增** `scripts/ui/panels/stats_panel.gd`（`StatsPanel`）：四个类型 —— **资源 / 单位 / 地块 / 领地**，默认 `res`。
- **资源表抽成 `Consts.RES_ABSTRACT` / `Consts.RES_CONCRETE`** —— 顶部资源栏与统计面板**共用同一份**。
  想加一种资源，加进常量即可，两边一起生效。
- `game_screen`：资源栏中间那个**纯占位 spacer 换成「统计」按钮**；`_toggle_stats_panel`；摆位用"在按钮正下方"（和"点资源弹收支窗"同一套位置逻辑）；**Esc 能关**。
- **资源页显示「当前 / 上限 + 每周期净收支」** —— 出图上能直接看到 **食物 −2.1、货币 −3.6 在亏**（红字），
  正好是试玩目标第 1 条"维持收支平衡"要盯的两行。
- 单位页含**客人 / 公民、空闲 / 已指派人力、按职业**，以及**编队数与各队人数**。
- 地块页：总格数 / 按地形 / 资源点。领地页：我方·敌方·无主 / 扩张消耗 / 可扩张格数 / 据点。

### ⚠️ 一个"绿着坏掉"的坑（值得记）

资源表一开始放在 `game_screen.gd` 里，`StatsPanel` 用 `GameScreen.RES_ABSTRACT` 去取 —— **编译不过**：

```
Parse Error: Identifier "GameScreen" not declared in the current scope.
```

原因：`game_screen.gd` **没有 `class_name`**（它一直是被各处按路径 `load` 的），跨文件引用它根本不存在。

**更阴的是：15 项自检全绿**，只有 `--import` 的输出里有 Parse Error。
→ 正确做法（也是项目一贯的做法）：**数据放 `Consts`**（`scripts/data/constants.gd` 有 `class_name`）。

> 教训：**光看自检绿不绿不够，还要看 `--import` 有没有脚本错误。**
> 这一类"编译不过但测试照跑"的情况，测试是发现不了的 —— 因为测试触到的加载路径跟编辑器扫描不是同一条。
