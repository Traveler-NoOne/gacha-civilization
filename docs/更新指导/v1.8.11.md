# v1.8.11 统计面板（追加段）

> 状态：⬜ 未开始（排期在 v1.8.10 之后）
> 来历：v1.8.7 要删掉「管理」入口，而**部队统计**是那里唯一没分到新家的功能。现决定为它单独立一个面板。

## 一、为什么不能塞进「据点管理窗口」

- **部队统计的本质是"整个大世界"的口径**：大世界上有多少单位、多少编队 —— 它不隶属于任何一个据点。
- **据点管理窗口将来要通用**：多据点玩法时，同一个面板会被每个据点各开一份。把一个"全世界"的数字塞进去，要么每个据点都重复显示一遍，要么就变成"只有首都能看"的怪东西。

→ 结论：**单独立一个「统计面板」**。

## 二、面板定位

**"能统计、但一时不知道该放哪"的东西的收容所。**

第一批内容（用户原话：能统计的都可以先放这边）：

1. **所有资源** —— 食物 / 货币 / 木材 / 煤 / 铜 / 铁矿 / 原油 / 水晶碎屑 / 科研点 / 行政点数 / 秩序结晶 / 凝聚力 …
2. **所有单位** —— 总数、按类型 / 据点 / 等级分组；以及**编队数**（用户明确：部队统计 = 有多少单位 + 多少编队）
3. **所有持有的地块** —— 总数、按地形 / 资源点分组
4. **领地** —— 我方领地 / 敌方据点 / 无主，含各自的掌控力与土地口径

## 三、位置与交互

- **位置：资源栏的中间**（顶部资源栏中段那块空着的地方）。
- **切换统计类型的按钮放在面板左侧**（竖排一列）。
- 内容区显示当前类型的统计。
