# 世界生成 · W3 —— 气候与柯本（S3 + S4）

> 状态：⬜ 未开始（用户将统一审阅）
> 依赖：W2
> 总纲：[世界生成-过程模拟.md](./世界生成-过程模拟.md)（第五节 S3 / S4、第四节 4.2 分层分辨率）

## 一、目标

算出**12 个月的气温与降水**，据此得到**柯本气候分类**与**生物群系** ——
让地图上出现**雨影沙漠、季风、极地/雪线**这类"一眼就觉得对"的地理。

## 二、做什么

### 2.1 S3 气候（**在 128×128 的粗网格上算**，见总纲 4.2）

| 量 | 怎么算 |
| --- | --- |
| **气温** | 纬度带（把死地图的 y 映射成纬度）+ **季节相位**（12 个月）+ **海拔递减**（越高越冷）+（可选）海陆热容差 |
| **降水** | **风带**（0~30° 信风 / 30~60° 西风 / 60~90° 极地东风）+ **海洋水汽源**（从海面出发）+ **迎风坡抬升**（水汽沿风向累积 → 遇山抬升 → 多雨）+ **背风坡递减**（雨影） |

> ⚠️ 顺序依赖：**必须先有高程与水域**（才知道水汽从哪来、山在哪），所以这一步吃 W2 的结果。

### 2.2 S4 柯本 + 生物群系

- 用**月均温 + 月降水**套柯本判据（Af/Am/Aw/BW/BS/Cs/Cf/Df/ET/EF…）。
- **生物群系 = 柯本 + 高程**（高山、雪线）。
- 把 biome **上采样**到 512，供 W5 的采样转换用。
- 输出**正好喂给现有的两层**：`terrain`（地貌）+ `cover`（地物）→ 这是 v1.8.21 就留好的口子。

## 三、验收

1. **人看**：地图上能看到
   - **山脉背风侧是干旱区**（雨影沙漠）；
   - **低纬多雨、极地严寒**；
   - 森林/草原/沙漠/雪原**成带分布**（不是随机撒点）。
2. **同种子两次生成逐位一致**。
3. 4 个无头自检全绿。

## 四、范围外

- **不做洋流**（可留接口，将来再加；它影响不大但成本不小）。
- **不做"真实地球经纬度"**：这是一块**平面区域**，纬度是"映射出来的"，不是真球面（总纲第十一节）。

## 五、风险

- 12 个月 × 128×128 = **约 20 万个"格·月"**，是**本项目最大的一笔算力开销**。
  要在 W3 里**实测生成耗时**并定默认质量档（总纲第十节把它列为"必须实测的数"）。
- 柯本判据的**阈值细节**属可逆参数（助理按国际标准实现，再按观感微调）。
