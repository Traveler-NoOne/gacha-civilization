# 世界生成 · W2b —— 陆壳/洋壳 + 造山带成型

> 状态：🔨 **进行中**（2026-10-13 由用户的追问引出：「会不会出现**隔断印度和中国的那种喜马拉雅山脉**？以及**科迪勒拉山系**那种自然宏观？」）
> 依赖：W2（板块已接成高程）
> 总纲：[世界生成-过程模拟.md](./世界生成-过程模拟.md)

## 一、为什么要插这一段（**是依赖，不是好看**）

W2 做完之后，地图上确实出现了"成条"的结构，但**山脉是散点、最长才 5~6 格**（全图只有 31 格山脉）。原因有三：

1. **山脉是"碰阈值碰出来的"**：板块最多给 +0.22，而山脉要 `e ≥ 0.72`（`world_gen.biome_of()`）
   → 只有底子本来就高的格子才越过线，于是山带里**一段是山、一段是丘陵**；
2. **没有"陆壳 / 洋壳"的概念**：判"这一侧是海还是陆"用的是**逐格噪声底高**
   → **同一条边界上会一段抬成山、一段压成沟**，而真实世界的整条边界是**同一种**相互作用；
3. **没有"碰撞后方的高原"**：喜马拉雅是"山墙 + 青藏高原"，不是一条细线。

> ⚠️ **为什么必须排在 W3（气候）之前**：W3 要做的**雨影**，前提是"山脉是一条**连续的长墙**"——
> 山是散点 → 雨影就是散点；山是长墙 → 背风侧才会出现**一整条沙漠带**。
> 所以"山的连续性"应当先做扎实。

## 二、要做的两件事

### 2.1 给板块一个「地壳类型」（陆壳 / 洋壳）

- 边界类型随之**细分**（这才是真实地理里的四种相互作用）：

  | 相遇方式 | 地壳组合 | 结果 |
  | --- | --- | --- |
  | 相向 | **陆 + 陆** | **碰撞造山**：又宽又高的山系（喜马拉雅型） |
  | 相向 | **洋 + 陆** | **俯冲**：洋侧**海沟**、陆侧**沿岸山链**（科迪勒拉/安第斯型） |
  | 相向 | **洋 + 洋** | **岛弧 + 海沟**（西太平洋型） |
  | 相离 | 陆 + 陆 | **陆内裂谷**（往下陷） |
  | 相离 | 含洋 | **洋中脊**（洋侧微抬） |
  | 错动 | 任意 | 垂直方向不动 |

- **实现上的近似（可逆）**：地壳类型先用"**种子离世界中心的远近**"判
  （地图本来就是"中间陆、四周海"，所以中心附近的板=陆壳、靠边的=洋壳），
  **不用**去采样每个板块的基础高程均值（那会引入 `Plates → WorldGen` 的循环依赖）。
  → **W5 有了真正的参数图之后应当改成"按板块覆盖区域的平均基础高程"判**，这才符合过程。

### 2.2 造山带"成型"（**这一段的关键**）

不再靠"加一点高度去碰 0.72 阈值"，而是给一条**连续的山脊线**：

```
d     = 这一格到边界的距离（1..W）
ridge = 1 - (d - 1) / W          # 边界上 = 1，到 W 格外 = 0
e    += amp * ridge              # amp 按"相互作用类型"分级
```

- **amp 必须够大**：陆-陆碰撞取 **0.34**，这样"底子 0.40 的陆格"也一定能顶到 0.74 → **越过山脉线**，
  于是**整条边界连成一条长墙**，而不是碰运气；
- **带宽按类型分级**：碰撞 5 格（宽，像喜马拉雅）、俯冲 4 格（沿岸山链）、裂谷/洋中脊 3 格；
- 俯冲的**洋侧要往下削**（海沟），这样才有"海沟 + 沿岸山链"的成对结构（= 科迪勒拉）。

## 三、验收

1. **形态断言（把"喜马拉雅感"变成可测的）**：`plate_check` 里新增一条 ——
   **全图"连续山脉格"的最长连通长度 ≥ N 格**（W2 后实测只有 5~6 格；做完这一段应当几十格）。
2. **符号断言按地壳类型重写**（原来按"逐格海陆"判，现在该按"陆/洋"判）：
   陆-陆碰撞两侧都抬高；洋-陆俯冲的**洋侧压低**、**陆侧抬高**。
3. 5 个无头自检全绿；截图 + 识图确认"**成条的长墙**"（这一条交人看）。
4. 地图仍然**逐格可复现**（W1 定的约定）。

## 四、范围外

- **岛弧的具体形状**（海沟—岛弧—弧后盆地那套）：先只做"洋-洋相向时的岛弧隆起"，
  弧后盆地等以后再说。
- **碰撞后方的高原**（青藏高原那种"山墙 + 高原"）：**留到 W2b 第二半或以后** ——
  它是"喜马拉雅味道"的关键，但不是气候的前置条件。
- 不动地形阈值（`biome_of` 的 0.36/0.50/0.62/0.72）——那是"高原/山脉到底算不算山"的尺子，
  要改也该等看过 W2b 的结果再调。

## 五、风险

- **amp 调大可能把海填成陆**：碰撞带若穿过海面，抬 0.34 会把海抬成陆地。
  地壳类型（陆-陆才有大 amp）正是为了防止这个；若仍出现"海上凭空长山"，那是**地壳判据不对**，
  应当去改判据，而不是去压 amp。
- 这一段**只改板块效应**，不动噪声、不动湿度、不动阈值 → 出问题容易定位。

## 第二轮（2026-10-13 晚，用户说"开始 w2b 吧"之后）

### 修掉的两个真 bug（都是自检 + 识图一起抓出来的）

1. **地壳类型判据错了** → 改成"按该板**覆盖地块的基础高程均值**"判（`WorldGen.crust_for()`）。
   **第一版按"种子离世界中心的远近"猜**，于是**陆壳板实际覆盖的是海** → "陆-陆碰撞"发生在**海中央**，
   抬出一堆海上孤山，**长不出长墙**（识图说"远未达到长山墙"的一半原因在这里）。
   ⚠️ 判据必须用**不含板块作用**的基础高度算均值（用含板块的高度会自己引用自己）——
   所以把 `world_gen` 的高度拆成了 `base_elevation_of()`（基础）与 `elevation_of()`（基础 + 板块）。
2. **`boundary_for()` 取的是"全局最强"的边界，而不是"最近"的** → 一条山带的 `d` 会指向 5 格外的
   强边界（而 `d=5` 已在带外 → 效应 0）→ **山带被撕成碎块**。
   改成**按距离由近及远找、只在同一圈里比强度**（新增 `_ring()`）。

### ⚠️ **仍未达标**（如实记，W2b 不算完成）

平均宽 **6.1 > 2.5** → 眼睛里它仍是**"带 / 网"，不是"山墙"**。

而且这一轮发现**我的"薄度"指标本身是错的**：`面积 / 直径` 对"**网**"没有意义 ——
几条山带相交时会被连成一个连通块，于是**把"网的跨度"当成了"墙的厚度"**。
（这也是"数值说 109 格、眼睛说不是墙"的真正原因：**指标和眼睛量的不是同一件事**。）

**下一步（换指标，再调参）**：

1. **先换一个正确的"薄度"指标**，候选：
   ① 只统计"**沿同一条边界**的山格"（按 `boundary_for().other` 分组，看每一组的长度与宽度）；
   ② 对山脉格做一次**形态学细化**（细到 1 格宽的骨架），量骨架长度；
   ③ 量**最长简单路径**（而不是最大格距）。
2. **拿新指标去调参**；若仍不像，就说明"加成高度去碰阈值"这条路本身不对 ——
   那时应当把山脉定成**沿边界的一条折线**（而不是一个带宽带），即真正做"山脊线"。
3. 达标后再**交用户看**（"像不像山系"最终只有他能判）。
