# 1.8.20.4 · 左键交互模型改版 + 悬停看地块信息

> 状态：✅ 已完成
> 起因：用户发现「左键点首都的地块，既选不中棋子、也不弹地块信息 —— 呆在首都的棋子等于卡死」。

## 一、旧模型漏掉了「首都」这一档

旧的三档分派是：点中棋子图标 → 选单位 / 我方领地 → 开据点面板 / 其它 → 弹简约信息小窗。
但**首都同时也是我方领地**，于是：

- 点在格子上（不是图标上）→ 走"我方领地"档 → 开据点面板 → **`return`**，永远到不了弹信息那一档；
- 而据点面板**不认格子**（`refresh()` 里读的是 `GameState.current_stronghold()`＝`strongholds()[0]`），
  点哪一格打开的都是同一个；
- "选单位"的入口只有"点中图标"一条，**根本没被碰到**，而且旧代码还会顺手把 `sel_uid` 清空。

对照：被删掉的旧轮换序列里**专门有** `cands.append("capital")`（首都是一等公民）——
`4287ff9`（v1.8.2-C）换成三档分派时，**首都那一档没有对应物**。

## 二、新交互模型（用户定的）

| 操作 | 结果 |
| --- | --- |
| 鼠标悬停任意格 | 悬停 **1 秒**后显示地块信息小窗（不依赖点击） |
| 左键点单位图标 | 选中该单位 |
| 左键点首都星 | 打开**这一格**对应的据点面板（认格子） |
| 左键点我方其它格 | 只更新 `selected`，不弹面板、不弹信息 |
| 左键点空白 / 敌方格 | 取消选择，什么都不打开 |
| 右键 | 原逻辑不动 |

## 三、实现

- `hex_map_view.gd`
  - 新增信号 `hover_changed(key)`：悬停换格时发；**开始拖动平移时发 `""`**（平移途中不该显示信息）。
  - 抽出 `tile_center(key)`（格心），并让 `unit_icon_positions()` 也改用它 —— 绘制与命中同源。
  - 新增 `capital_star_hit(key, global_pos)`：**半径与绘制共用** `_draw_tile_stronghold()` 里的
    `hex_size * 0.42`（看到多大就能点多中）。坐标转换（全局→本地）放在它内部，调用方不用操心。
- `view_world_page.gd`
  - `_on_tile_clicked()` 按新模型重写成四档：棋子图标 → 首都星 → 我方其它格 → 取消选择；
    并且**点击一律先收起小窗**（小窗归悬停管）。
  - 新增 `_on_hover_changed(key, at)`：自增 `_hover_seq` 后等 1 秒；期间若又换了格 / 进了选地模式 / 页面不可见，
    这次就作废。`at` 可显式传位置（测试用），不传就用鼠标位置。
  - `_open_stronghold_panel(key)` 带上了格子。
- `stronghold_panel.gd`：面板加 `key`，`refresh()` 改按
  `GameState.stronghold_by_id(GameState.stronghold_of(GameState.tile_at(key)))` 找据点
  —— **两个函数都是现成的**，没有新增 GameState 接口。（`key` 为空时退回旧的 `current_stronghold()` 兜底。）

## 六、给后来人两条

1. **小窗只由悬停负责**，点击一律先收起它。要加"点哪里弹什么"，别再把 `_show_tile_info` 塞进点击路径。
2. **测试里凡是靠悬停弹出的镜头，必须先 `Input.warp_mouse(点)`**：截图是真窗口跑的，鼠标若在窗外，
   会触发一次"移出地图"的悬停把小窗收掉（这次就踩了，`08a` 拍出来是空的）。
