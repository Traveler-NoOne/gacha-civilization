# 1.8.20.7 · 左键信号更名：`tile_clicked` → `tile_left_clicked`

> 起因：用户要求把 `signal tile_clicked(key, uid, gpos)` 更名为 `tile_left_clicked`。

## 一、改了什么（全项目 grep 后，真正要改的只有 3 处）

| 文件:行 | 内容 |
| --- | --- |
| `scripts/ui/hex_map_view.gd:11` | `signal tile_left_clicked(key: String, uid: String, gpos: Vector2)` |
| `scripts/ui/hex_map_view.gd:392` | `tile_left_clicked.emit(k, uid, ...)` |
| `scripts/ui/views/view_world_page.gd:97` | `map.tile_left_clicked.connect(_on_tile_clicked)` |

## 二、明确**没动**的

1. **处理函数 `_on_tile_clicked` 保留原名。** 要改的是 **signal**；handler 是另一个名字。
   真要一起改成 `_on_tile_left_clicked`，得同步改 9 处测试调用
   （`diag_v110:81`、`diag_v15:210/218/237/255`、`diag_v16:69/105`、`screenshot:306/454`）——
   属于另一件事，等用户发话。
2. **两份历史文档里的旧名不改**：`v1.8.2.md`（那是**引入这个名字**那一段的记录）、
   `1.8.20.4.md`（写的是 handler 名）。版本记录与更新指导是**历史**，回头改会失真。

## 三、顺手补的一条断言（这次真正的风险点）

**风险**：这类更名最容易漏的就是"**接线**"那一处，而漏了**不会报错** ——
只会让左键**静默失效**（地图发了信号，没人接）。

**而现有测试全都覆盖不到它**：
- 自检与截图都是 `call("_on_tile_clicked", ...)` —— 直接调处理函数，**绕过接线**；
- `diag_cheat_mouse` 用真实鼠标事件，但它点的是作弊菜单，**不点地块**。

→ 在 `tests/diag_v15.gd` 里补了一条：检查 `tile_left_clicked` 的连接，
并要求**接的确实是 `_on_tile_clicked`**（不只是"有连接"）。
以后谁再把接线改错/漏掉，这条会拦住。输出形如：

```
左键信号 tile_left_clicked 接的是 _on_tile_clicked？true（1 条连接）
```

## 四、验证

- `--import` 重扫干净（**注意它不解析 `tests/` 下的脚本**，所以这只是半张网）。
- **全套自检 15 / 15** ✓，其中新断言通过（见上）。
- **未跑截图**：更名不可能改变任何像素；而真正的风险（接线）已由上面那条断言直接覆盖。
