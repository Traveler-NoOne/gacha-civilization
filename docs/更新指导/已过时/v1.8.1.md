# v1.8.1 · 地图分图层绘制

## 一、目标

把大世界地图的绘制从**"一格一格画完所有内容"**改成**"一层画完再画下一层"**。

**顺带修掉一个真 bug**：据点名（`首都·初始营地`）显示不全——名字画在格子下缘，那里六边形收成一个尖（没有横向空间），文字伸出本格后被**后画的邻格盖住**；而且"谁盖谁"取决于字典遍历顺序，所以**时好时坏**。

## 二、设计

**图层顺序（越底层越先画）**：

| 层 | 内容 |
| --- | --- |
| 1 | **底色**：地形底色 / 迷雾 |
| 2 | **特征物**：资源点 |
| 3 | **领地与据点**：势力边框、首都 ★、敌方据点标记 |
| 4 | **建筑**：小方块 + 已指派人力的黄点 |
| 5 | **单位**：驻军条 + 数量 + 职业图标 |
| 6 | **标记与高亮**：外部标记（marks）、悬浮/选中 |
| 7 | **文字**：据点名 / 敌方标签 —— **最后一层，谁都盖不到它** |

> 这个顺序同时解决了"文字被盖"，也为以后加图层（比如地块边界、路线、特效）留了位置。

## 三、拆成两个小步（重要：先重构、后改行为）

### 1-A 纯重构：把每一层抽成独立函数，但**仍然按格调用**

- `_draw()` 里对每个可见格子依次调用 7 个层函数。
- **行为必须与现在完全一致**——包括那个"名字被盖住"的 bug 也还在。
- **验收方式很硬**：截图自检跑一遍，**地图区域与改前逐像素一致**（这是"重构"与"改行为"的分界线）。

### 1-B 改循环：把"按格循环"改成"按层循环"

- `_draw()` 变成 7 个循环，每个循环遍历所有可见格子画一层。
- **这一步之后 bug 消失**：文字在最后画，邻格盖不到。

## 四、涉及文件

- `scripts/ui/hex_map_view.gd`（`_draw()` / `_draw_tile()` 重构为 7 个层函数）
- 顺带抽出 `_visible_tiles()`：把"视口裁剪"收成一个函数，7 层共用（避免每层各写一遍裁剪）。

## 五、验收

1. **1-A 后**：截图自检的地图区域与改前**逐像素一致**（我会用像素对比来验）。
2. **1-B 后**：
   - 首都的名字 `首都·初始营地` **完整显示**；
   - 扩张出来的地块**一个字都没有**（现状已达成，不能回退）；
   - 敌方地块的 `危险/威胁/敌人` 标签照旧。
3. `跑自检.bat` → **12/12**。
4. 试玩确认：拖动、缩放、悬浮高亮、选中都不变。
