## 一、bug#8：人力页行末那个「括号里的东西」到底是什么

### 先纠一个误读（这条比修改本身重要）

清单当时记的是「**经典学院 Lv.1（-2.0）**」「**经典田地 Lv.1（0.0）**」，并怀疑它跟修建浮窗的
「幸福度：基础 **-2.0**，每级 **+0.0**」**对不上**。

**实地读码后：这不是数值不一致，是看错了。** 那一行真正的格式是：

```gdscript
# stronghold_panel.gd:281
UIKit.text_label("%s Lv.%d（%s）" % [def.display_name, level, key], 11, UIKit.TEXT)
```

括号里是**格子的 key**（`世界生成` 用的 `"q,r"` 坐标串），**不是任何数值**。
`-2,0` 在小字号下**逗号看起来就是小数点**，于是被读成了 `-2.0`；`0,0` 被读成了 `0.0`。
（顺带解释了 bug#7「鼠标附近那个只写 `0.0` 的小方块」——同一类观感事故：
**一个 `"q,r"` 坐标标签在小字号下看着像一个小数**。）

### 那还要不要改？要。改的是"没有标注"

问题不在数字，在**没写清括号里是什么**：

| 现状 | 建议 |
| --- | --- |
| `经典学院 Lv.1（-2,0）` | `经典学院 Lv.1　地块 -2,0`（把格 key 明写成"地块"） |
| 或者更彻底 | 把格 key 放到**次要颜色**（`UIKit.TEXT_DIM`）并加前缀，让"它是坐标不是数值"一眼可辨 |

**判据**：一个没看过代码的人扫一眼，不会把它读成小数。改完请**用那张图自己看一眼**
（这正是"玩家能不能正确推断含义"那条要求的用法）。

> 顺带一句：**不要**为了这条去改 `q,r` 的坐标格式本身 —— 那是存档键，动它会牵动存档与纯函数约束。

## 二、bug#10：浮窗标题重复（只重复在 2 个地方，不是普遍现象）

**机制**：浮窗外壳（`PagePanel` / `LogPanel`）的标题栏已经画了一次标题，
而**被装进去的页面**自己又画了一次大标题：

| 浮窗 | 外壳画的 | 页面自己又画的 | 重复？ |
| --- | --- | --- | --- |
| 至宝 | `page_panel.gd:31` →「至宝」(15) | `treasure_view.gd:31` →「至宝」**(20)** | ✗ **重复** |
| 日志 | `log_panel.gd:23` →「日志」(12) | `log_view.gd:31` →「日志」**(20)** | ✗ **重复** |
| 世界泡 | 「世界泡」 | `gacha_view.gd:47` →「**召唤系统**」 | ✓ 不重复（那是当前子系统名，**保留**） |
| 科技树 / 据点 / 修建 / 统计 | 各自的标题栏 | 页面内没有同名大标题 | ✓ 不重复 |

**改法（推荐）**：删掉**页面里**那个大标题（`treasure_view.gd:31`、`log_view.gd:31`），
**保留外壳的标题栏** —— 理由是：

- 外壳标题是**所有二级浮窗统一的窗口标识**，它就挨着 ✕，玩家靠它认"这是什么窗"；
- 两个页面的那一行 `head` 里**还并排着一句有信息量的说明**
  （至宝：「所有世界泡产出（非消耗品）都会归入这里」；日志：「任务追踪、存档管理、内容图鉴、名词手册」），
  删掉标题后这行仍然成立、仍然有用；
- 反过来（删外壳、留页面）会让日志浮窗的标题栏只剩一个 ✕，更难认。

**改完的验收**：`04_view_treasure` 与 `12_log_manual` 两张图里，各标题**只出现一次**。
