# 作弊菜单分页（资源 / 世界 / 杂项）

> 状态：✅ 已完成（2026-10-13）
> 起因：用户要求"给作弊菜单加功能：面板上放三个按钮——资源 / 世界 / 杂项；
> 各种资源货币归资源页；世界页先只放'点亮所有迷雾'；击杀放杂项"。
> 歧义已当场问清，用户全选"推荐项"。

## 决定（用户确认）

| 问题 | 选择 |
| --- | --- |
| 三个按钮的形式 | **顶部页签**：三个按钮一直可见，点哪个下面就是哪一页 |
| 「点亮所有迷雾」 | **把全图所有格子标为已发现**，**一次性动作**（不能盖回去） |
| 杂项里的「击杀」 | 就是原来的「摧毁敌对单位」**整块搬过去**（保留逐个摧毁 + 摧毁全部） |

## 做法

- `game_screen.gd`：`_open_cheat_menu()` 重构成**页签式**（标题 + 警告行 + 页签栏 + body + 收尾提示），
  切页时**清空 body 重建**（这样"敌对单位列表"每次进来都是最新的）。
  原来那两块内容**整块原样搬**进新函数，**没有重打**（用行级搬运，切之前先断言边界行的内容）：
  - `_cheat_page_resources(v)`：原来「添加资源」整块（9 种资源 + 快捷 +100/+1000/清零 + 一次性添加）
  - `_cheat_page_misc(v)`：原来「摧毁敌对单位」整块（逐个摧毁 + 摧毁全部）
  - `_cheat_page_world(v)`：**新写**，只有一个「点亮所有迷雾」按钮
- `game_state.gd`：新增 `cheat_reveal_all()` —— 把所有地块标为 `discovered = true`，
  记日志 + toast + `state_changed`（与既有 `cheat_*` 写法一致）。**一次性，不可逆**。

## 实测

- 6 个无头自检全绿；截图 45 张无报错。
- **识图核对** `19_dialog_cheat`：三个页签横排在标题下方（**资源 / 世界 / 杂项**），
  「资源」高亮；资源页内容完整；**弹窗未被裁掉**、底部按钮与提示完整可见；无布局问题。
- `19_dialog_cheat` 像素差 **3.02%** —— **预期**（这个窗口被重构了），不是回归。
