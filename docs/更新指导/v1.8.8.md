# v1.8.8 · 世界升格为 root

## 一、目标

把**大世界**从"五个平级页面之一"提升为**游戏底层（root）**；**管理 / 日志 / 世界泡 / 至宝** 变成它上面的**二级浮窗**。

> 依据：绝大多数 4X 游戏的大地图都是 root 级。而且这也贴合本作设定——**世界泡就是舞台本身**，其他系统都是"在这个舞台上打开的窗"。

## 二、设计

- **世界地图常驻**：任何时候都在，不会被"切走"。
- **四个二级窗口**：
  - **日志** = 居中大浮窗（四周留边，**能看见底下的世界**）——这是"浮窗感"的标准样板（v1.8.6 已做）
  - **世界泡 / 至宝** = 大浮窗（尺寸待试玩后定）
  - **管理** 已在 v1.8.7 消失
- **关闭浮窗 = 回到纯地图**（Esc、关闭按钮、或点浮窗外的地图区域——**三选一或都做，试玩定**）。
- **世界地图在浮窗打开时的行为**：建议**压暗但不禁止拖动**（保留"我在世界之上操作"的感觉）；如果实测手感差，再改成阻断。

## 三、涉及文件

- `scripts/ui/game_screen.gd`：从"内容区切换视图"改成"世界常驻 + 浮窗叠加"
- `scripts/ui/view_host.gd`：核心改造——由 `show_view(全屏页)` 变成 `open_panel(浮窗) / close_panel()`
- 各视图的根节点：从"全屏 `Control`"改成"有明确尺寸与位置的浮窗面板"
  - `view_manage_page.gd`（已废，不动）
  - `log_view.gd`、`gacha_view.gd`（世界泡）、`treasure_view.gd`（至宝）

## 四、风险与注意

- **`view_host` 是这次改动的震中。** 它现在负责"缓存视图 + 切换时刷新"（v1.6 修过的那个 bug 就在这儿）。改成浮窗后，**"切回时刷新"这条保证不能丢**——否则会重现"修建后进管理页看到空列表"那类问题。
- **测试影响最大的一段**：截图自检的 36 张图几乎全部会变（视角变成"地图 + 浮窗"）。
- **`_switch_view` 的调用点很多**（各视图互相跳转，如至宝跳世界），改造时要逐个确认。

## 五、验收

1. 任何时候地图都在底层；打开任一浮窗都能看出"世界还在下面"。
2. 关闭浮窗回到纯地图；再从角落按钮打开任一浮窗，**内容是最新的**（不能出现旧缓存）。
3. 视图之间的跳转（如"至宝 → 招募 → 跳到世界选地"）**仍然走得通**。
4. `跑自检.bat` → 12/12。
5. 截图自检 36 张**全量重拍**并逐张确认。
