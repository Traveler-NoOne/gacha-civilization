### 4. C：`project.godot` 被写坏的两行

- **位置**：`project.godot:30-31`
- **现状**：
  ```
  "#⚠️1.8.20备忘（都别踩）：…写resizable"=false
  "让无头测试拿到可用视口…。[editor_plugins]enabled"=PackedArray()
  ```
  即：一条**注释**被当成键名，并且把 `[editor_plugins]` 这个**段头吞进了引号里**。
  （来源：2026-10-11 那几次"整块替换把文件写坏"的事故，见 `1.8.20.md` 的踩坑记录。）
- **为什么现在没炸**：`[display]` 段里的未知键引擎会忽略；项目里也没有 `addons/`，`editor_plugins` 空着不影响。
  但文件是脏的，**留着就是下一个事故的种子**（它的段头已经没了，将来谁加 editor 插件会莫名其妙不生效）。
- **改法**：
  1. 把这两行**精确替换**成合法的东西 —— 备忘若要留，就写成**真正的注释**（`;` 开头）；
     `[editor_plugins]` 段头要**单独成行**、恢复它的段。
  2. **改完立刻 `git diff project.godot` 核对**（只许少这两行垃圾，不许动 `[display]` / `[gui]` / `[rendering]` 的真设置）。
  3. 引擎能正常启动 + 自检全绿 = 通过。
