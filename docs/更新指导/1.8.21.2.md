### 4. C：`project.godot` 被写坏的两行

- **位置**：`project.godot:30-31`
- **现状**：
  ```
  "#⚠️1.8.20备忘（都别踩）：…写resizable"=false
  "让无头测试拿到可用视口…。[editor_plugins]enabled"=PackedArray()
  ```

  即：一条**注释**被当成键名，并且把 `[editor_plugins]` 这个**段头吞进了引号里**。
  （来源：2026-10-11 那几次"整块替换把文件写坏"的事故，见 `1.8.20.md` 的踩坑记录。）

  但文件是脏的，**留着就是下一个事故的种子**（它的段头已经没了，将来谁加 editor 插件会莫名其妙不生效）。
- **改法**：
  1. 把这两行**精确替换**成合法的东西 —— 备忘若要留，就写成**真正的注释**（`;` 开头）；
     `[editor_plugins]` 段头要**单独成行**、恢复它的段。
  2. **改完立刻 `git diff project.godot` 核对**（只许少这两行垃圾，不许动 `[display]` / `[gui]` / `[rendering]` 的真设置）。
  3. 引擎能正常启动 + 自检全绿 = 通过。

### 做法上的两个关键选择

1. **`project.godot` 用"字节级行手术"，不用整块替换**。原文那两行是**双重编码**的乱码
   （UTF-8 字节被当成 cp1252 又存了一遍），且 cp1252 有 5 个未定义字节（`0x81/0x8D/0x8F/0x90/0x9D`）
   已经**丢过字节**、无法逐字还原。所以：先做安全校验（确认第 30/31 行确实分别以 `=false` 与
   `PackedStringArray()` 结尾，否则**中止且不写入**）→ 只替换这两行 → 立刻 `git diff` 核对。
   **不编历史**：只保留它能表达的两条信息（"窗口锁定不写在这里"），并写明这一段原本是被写坏的键。
2. **验收方式从"grep 源码"改成"运行期文案断言"**（见下）。

### 新增护栏：`tests/dead_ref_check.tscn`（4 组断言）

为什么必须新增：这三处文案**不会让脚本报错、原有自检也不会红** —— 只有玩家照着走才会撞墙。
而**源码 grep 不能当验收标准**：注释里**故意保留**了"原来指向哪、为什么改"（总规则第 7 条），
所以源码里当然还搜得到旧词。真正该断的是**运行期出现在界面上的文字**。于是：

- ③ 角色页**无单位时的空状态**：不含旧词 + 指向「政事」。

**护栏自己也验证过会红**：临时把一处改回「管理页」→ `[FAIL] …（命中：["管理页"]）`、exit=1；
改回 → 全绿。
