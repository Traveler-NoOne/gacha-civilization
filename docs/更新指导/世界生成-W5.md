## 一、目标

把"**一张大死地图**"变成"**一块半径 21 的六边形地块图**"：
先按条件**裁一块六边形区域**，再把这块区域**采样转换成地块**。

## 二、做什么

### 2.1 S6 裁切（第七节）

| 层 | 内容 |
| --- | --- |
| 用户口径 | **海陆比 25%~75% 都算合格**（很松，只是"别太离谱"，不是门槛） |
| 第 1 层：淘汰 | 全海 / 全陆、海陆比超出 25%~75%、**窗口超出图边**（中心必须留足边距） |
| 第 2 层：排序 | 在合格的里按 **`|海 − 陆|`** 取最接近 50:50 的 |
| 第 3 层：形态（W6 时再加） | **群岛 vs 大陆**：陆地**连通块数** + **最大块占比** + **海岸线曲折度** |
| 实现 | **滑窗扫描**（粗到细：先在粗网格上扫候选，再在最优附近细调），窗口为**六边形** |

### 2.2 S7 采样转换（总纲 5.4）

| 项 | 规则 |
| --- | --- |
| **高程** | 格内**面积平均**（**不要只取中心点** —— 否则地形规则化、海岸线像尺子画的） |
| **海 / 陆** | 格内**水域占比 > 50%** 才算水 → 海岸线自然、小岛留得住；再加"**小于 X 平方像素的孤岛丢弃**"防噪声碎岛 |
| **地形 / 地物** | 按 `biome` + 高程**查表**（喂给现有 `terrain` / `cover` 两层） |
| **资源** | 沿用"木头←森林、煤/铜←山丘"的**按地貌**做法（不额外引入随机） |
| **河流 / 湖泊** | 按 W4 的规则产出 `state["edges"]` |

## 三、验收

1. **裁出来的图合格**：海陆比落在 25%~75% 内，且是**合格窗口里最接近 50:50** 的；
   把这个比例与窗口位置**打印出来**（便于人工核对与调参）。
2. **能真的显示**：半径 21 的六边形地块图能被现有渲染（`hex_map_view`）正确画出，
   海岸线自然、没有"锯齿状的大方块"。
3. **同种子 + 同裁切窗口 → 逐位一致**；4 个无头自检全绿。
4. **人看**：这张图**像一张地图**（有海岸线曲折、有岛、有海）。

## 四、范围外

- **不做玩家可选**（群岛/大陆、卡池组、质量档都在 W6）。
- **不做拼接**（W7）。
- **不为"好看"去调高程阈值** —— 只允许为了"更像真实地理"而调（总规则第 8 条）。

## 五、风险

- **采样规则是"观感"的关键**：面积平均 vs 中心采样、水陆的 50% 阈值、孤岛阈值 ——
  这三样都会明显改变海岸线长相。助理会**各出一版图**给用户挑（这属于可逆参数）。
- 裁切窗口是**六边形**，要小心"窗口落到图外"的边界情况（第 1 层已含淘汰规则）。

## 进度（2026-10-13）：**死地图 + 裁切窗口**（W5 第一步，用户"w5 开工"）

### 做了什么（`climate.gd`）

- **死地图**：参数图不再只覆盖"世界那么大"，而是覆盖 **世界外接矩形的 1.5 倍**（`DEAD_SCALE`）；
  网格分辨率**同步放大**（128 → **192**），**保持每格像素尺寸不变**。
- **裁切窗口**：新增 `set_crop(像素偏移)` —— 世界坐标采样时先加这个偏移，
  于是"同一颗种子、不同窗口 = 不同的世界"。
- **缓存按窗口区分**（换窗口必须重算）。
- 采样与风带纬度都按同一个约定走（`_crop` 参与），避免"温度用世界纬度、降水用死地图纬度"这种不一致。

### 一个**试过又改回来**的设计（重要，别重复踩）

第一版我把**纬度按死地图（行星尺度）算** —— 意图是"裁到极地就是寒带世界"。**但副作用不能接受**：

- 一块世界只占行星的一小截 → 世界内温差从 **34.5℃ 缩到 21.3℃**；
- 世界整体变暖 → 柯本干旱阈值抬升 → **沙漠一度占到全图 41%（572 格）**。

那是**用户没要求过的视觉变化**，所以我**把纬度改回"按世界自己算"**（每块世界冷暖俱全），
死地图/裁切的**机制照留**（它改变的是"你这一局落在死地图的哪一处" → 地形与降水不同）。
> "裁到极地 = 寒带世界"这个玩法**将来若要做，应当另加一个"纬度偏移"选项**，别动默认。

（另外试过把 `PRECIP_MM_PER_RAW` 放大一倍去压沙漠占比 → **一格都没少**（572→572），
说明"沙漠太多"的根因**不是标尺**而是**降水分布太偏**：空气在第一个迎风坡就把水汽放光、
内陆几乎零降水。真正的修法是 W3b 的水汽模型，例如调大 `RAIN_BASE` 让空气**沿途慢慢下**。已记档。)
