## 二、当前实现（改之前先看这个，别凭记忆）

`scripts/ui/menu_screen.gd` 的 `_open_settings()`（约 163~228 行）：

```
UIKit.dialog("游戏设置")
  └ list（VBox）
      ├ _section("画面设置")  → 分辨率 / 画质档位 / 帧率限制
      ├ _section("存档设置")  → 自动存档周期数 + 说明

  → **这直接影响「确认 / 取消」的含义**，见下面的待定项。

## 三、目标结构

```

## 四、分步（每步都能单独跑起来看效果）

### 12-A 结构：左按钮 + 右内容
- 四个按钮：**画面设置 / 辅助设置 / 音效设置 / 键位设置**（此时先把「辅助」的页里放原来"存档设置"的内容）。
- 用 `bind` 传参切换页面，**不要用闭包捕获局部变量**（GDScript 的 lambda 按值捕获，改了外面拿不到 —— 这个坑项目里踩过）。
- 四个页各自是一个 `VBoxContainer`，把原来那四段内容**原样搬进去**。
- 验收：打开设置 → 点四个按钮 → 右侧内容跟着换；「画面/音效」的控件仍然能用。

### 12-B 文案改名
- 「存档设置」→「**辅助设置**」；「操控设置」→「**键位设置**」。
- （顺手）**键位设置里那句说明是过期文案**：「快捷键：**1-5 切换功能页**」
  —— v1.8.7 已改成 **1 / 2 / 3**（至宝 / 世界泡 / 世界）。改不改你定，反正这段正在动。

### 12-C 右下角 [确认] [取消]  ← ⚠️ 需先定语义
现在所有控件都是"一改就生效"，所以两个按钮有三种做法：

| 方案 | 含义 | 代价 |
| --- | --- | --- |
| **A（推荐）** | 改动先**不生效**，点确认才应用；点取消**还原**成打开时的样子 | 要把四个值先存在局部变量里，确认时统一写下去 |
| B | 改动**照旧立即生效**，两个按钮只是"关掉窗口" | 最省事，但「取消」名不副实（改了的东西不回退） |
| C | 折中：**能被还原的**（分辨率 / 帧率 / 音量）走 A，**写存档的**（自动存档周期）立即生效 | 解释起来麻烦，不推荐 |

> 无论哪个方案，**「确认」和「取消」都要关掉弹窗**（`close_dialog()`）。

## 附：12-A 的具体改法（照这个敲）

**改一个函数：`_open_settings()`（约 163~228 行）。** 原来它是「一个 VBox 塞四段」，现在改成「左右两栏」。

### 1) 顶部：弹窗加宽 + 声明结构

```gdscript
func _open_settings() -> void:
	_close_dialog()
	var d := UIKit.dialog("游戏设置", 640.0)      # ← 原来没写宽度，加 640
	_dialog = d

	var outer := VBoxContainer.new()
	outer.add_theme_constant_override("separation", 10)
	d.set_content(outer)

	var mid := HBoxContainer.new()
	mid.add_theme_constant_override("separation", 14)
	mid.size_flags_vertical = Control.SIZE_EXPAND_FILL
	outer.add_child(mid)

	var tabs := VBoxContainer.new()               # 左栏
	tabs.add_theme_constant_override("separation", 6)
	tabs.custom_minimum_size = Vector2(130, 0)
	mid.add_child(tabs)

	var body := VBoxContainer.new()               # 右侧内容区
	body.add_theme_constant_override("separation", 8)
	body.size_flags_horizontal = Control.SIZE_EXPAND_FILL
	mid.add_child(body)

	var pages := {}                               # id -> VBox
```

### 2) 四个按钮 + 四个页

```gdscript
	for t in SETTING_TABS:
		var tid := str(t["id"])
		var pg := VBoxContainer.new()
		pg.add_theme_constant_override("separation", 8)
		pg.visible = false
		body.add_child(pg)
		pages[tid] = pg

		var b := UIKit.normal(str(t["name"]), 13)
		b.custom_minimum_size = Vector2(130, 34)
		b.pressed.connect(_switch_setting_page.bind(pages, tabs, tid))
		tabs.add_child(b)
```

文件顶部加常量（放在 `MENU_SCENE` 之类常量附近）：

```gdscript
## v1.8.12：设置菜单的四个类别（左栏按钮）。改名只改这里。
const SETTING_TABS := [
	{"id": "video", "name": "画面设置"},
	{"id": "assist", "name": "辅助设置"},      # 原「存档设置」
	{"id": "audio", "name": "音效设置"},
	{"id": "keys", "name": "键位设置"},        # 原「操控设置」
]
```

### 3) 切页函数（新加，放在 `_open_settings` 下面）

```gdscript
## 切设置页：只让选中那页可见，并把对应按钮点亮
func _switch_setting_page(pages: Dictionary, tabs: VBoxContainer, tid: String) -> void:
	for id in pages.keys():
		(pages[id] as Control).visible = str(id) == tid
	var i := 0
	for t in SETTING_TABS:
		UIKit.style_button(tabs.get_child(i) as Button, str(t["id"]) == tid)
		i += 1
```

> **为什么要 `bind` 而不是闭包**：GDScript 的 lambda **按值捕获局部变量**，
> 写 `b.pressed.connect(func(): tid_used_inside = tid)` 那种在循环里是拿不到正确值的（项目里踩过）。
> `bind` 是把参数**附加在信号后面**传进目标函数，不会踩这个坑。

### 4) 把原来四段搬进四个页

把原来那四组 `list.add_child(...)` 换成往 `pages["video"]` / `["assist"]` / `["audio"]` / `["keys"]` 里 `add_child`：

- 原来的 `list.add_child(_section("画面设置"))` 这一行**直接删掉**（左栏按钮已经写了类别名）；
- 其余控件原样搬，只是把接收者从 `list` 换成对应的 `pages[...]`；
- `_volume_row(...)` 里现在返回的是 `_row(...)` 包好的行，照样 `pages["audio"].add_child(...)` 即可。

最后（临时，等 12-C 再做）加一句让第一页显示出来：

```gdscript
	_switch_setting_page(pages, tabs, "video")
	add_child(d)
```

### 5) 这一步怎么验

双击运行游戏 → 主菜单 → 游戏设置：
- 左边出现四个按钮（画面设置 / 辅助设置 / 音效设置 / 键位设置），当前项**高亮**；
- 点「音效设置」→ 右侧变成三个音量条；点「键位设置」→ 右边是那段说明文字；
- 分辨率 / 帧率 / 音量的控件**仍然能用**；
- 弹窗**不超出屏幕**（宽 640、高由内容决定）。
