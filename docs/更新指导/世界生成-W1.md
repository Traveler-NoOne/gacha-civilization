# 世界生成 · W1 —— 松绑与数据模型（**观感零变化**）

> 状态：⬜ 未开始（用户将统一审阅）
> 依赖：无（**本项目的第 1 段**）
> 总纲：[世界生成-过程模拟.md](./世界生成-过程模拟.md)

## 一、这一段要干什么

**把地基换掉，但画面一动不动。** 现在的生成器是"**每一格各自算**"（纯函数），
要换成"**先生成整张死地图，再从上面裁一块**"。W1 不写任何新算法，
只做两件事：**拆掉旧约束**、**把新数据结构定死**。

## 二、具体做什么

### 2.2 定死新数据结构（**这一段最重要、也最不可逆的部分**）

| # | 新增/改什么 | 内容 |
| --- | --- | --- |
| 1 | `state["worlds"]` | **每块世界一份配方**：`dir` / `origin` / `seed` / `sim_size` / `climate_size` / `crop_center` / `crop_radius` / `map_radius` / `world_age`（= 侵蚀轮次，见总纲 3.6） |
| 2 | `state["edges"]` | **边的独立集合**，键 `"q,r,d"`；两类边 `river_edge` / `water_edge`；**owner = 两端坐标字典序较小者**；反向 `(d+3)%6` |
| 3 | **方向索引规范表** | 写进 `hex.gd` 的注释：**边 k（顶点 k→k+1）↔ `DIRECTIONS[(−k) mod 6]`**（总纲 3.3 那张表） |
| 4 | `state["counters"]` | 全局增量计数器（先放**敌人数**），**只允许单一入口修改** |
| 5 | 稳定度等**全局量改全局统计** | `stability()` 里的"地图总格子数 / 空白格子数"按**所有世界加总** |
| 6 | `SAVE_VERSION` **+1** | 老档按既有策略**直接删除**（提示"存档已过期，请新开一局"） |

> ⚠️ **计数器的纪律**（用户 2026-10-13 定：**不加自检断言，漂移由用户自己抓**）：
> 仍然必须**只走单一入口**（沿用现有 `clear_enemy_tile()` 这类函数）；
> 但**不新增**"计数器 ↔ 枚举对账"的断言。**别偷偷加**——用户明确说这浪费 token。

## 三、验收

1. **游戏完整可玩**（总规则第 1 条）。
2. **4 个无头自检全绿**（`seed_check` / `fatal_check` / `popup_measure_check` / `dead_ref_check`）。
3. **截图容差对比：45 张里除 `17_dialog_draw`（抽卡随机）外应全部零变化** ——
   这是"**换地基没搬家**"的证据（沿用 1.8.20 定下的 MAD ≤ 2% 规矩）。
4. 老档（`SAVE_VERSION` 旧的）能正确被识别为过期并删除，且**不污染当前局**。

## 四、范围外

- **不动任何生成算法**（板块/气候/河流都在 W2~W4）。
- **不做裁切器**（W5）、**不做拼接**（W7）。
- **不做 (B) 方案的"只存动态叠加"** —— 用户已定全量存地块（总纲 3.5 / 8.3）。

## 五、风险

- **这一段改的是存档格式与共享数据**，一旦定了就别再改（总纲第十二节把"边规范 / 配方字段 / 拼块结构"列为**不可逆**）。
- `edges` 与 `counters` 现在**没有消费者**（要在 W4/W7 才用上）→ W1 只把它们建起来并写清规范，
  **不要为了"看起来有用"就提前接一半**（避免半成品逻辑留在代码里）。
