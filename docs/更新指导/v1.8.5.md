# v1.8.5 · 修建建筑（右键菜单 + 球形锤子 + 中型浮窗）

## 一、目标

给"修建建筑"做一个新入口：**右键地块 → 球形图标按钮菜单 → 🔨 → 中型浮窗里选建筑 → 修建**。做完之后，**删掉旧的右侧规划面板**（修建的搬家才算完成）。

## 二、设计

### 右键菜单

- 在**右键点击的地块附近**弹出一个小菜单。
- 里面的按钮都是**球形图标**（与 v1.7.1 的世界球同一套视觉语言）。
- **目前只有一个**：🔨 = 修建建筑。
- 结构上要**可扩展**（以后会加别的：拆除、驻军、巡查…）——所以做成"一组数据驱动的球按钮"，不是写死一个。

### 修建浮窗（中型）

```
┌──────────────────────────────────────┐
│  可修建建筑（列表，可滚动）              │
│   · 经典田地      占地 0.4  消耗 10 生产力 │
│   · 经典面包坊    占地 0.3  消耗 20 生产力 │  ← 点条目看完整效果
│   · …                                  │
│                                        │
│  [取消]                        [修建]   │
└──────────────────────────────────────┘
```

- 中间是**建筑列表**：可查看**建筑效果**与**生产力条件**（沿用现有 `building_db` 的描述文本与 `can_build` 判定）。
- **左下角两个按钮**：
  - **`取消`**：**不需要选中任何条目就能按**。
  - **`修建`**：**选中条目后才亮起**（未选中 = 灰/禁用）。

## 三、要顺手做对的一件事（重要）

v1.7.1 做的世界球按钮（`UIKit.bubble_button` / `apply_icon_active`）**不要删——要泛化**成通用球形按钮：

```
UIKit.sphere_button(图名, tooltip, 直径)   ← 世界球和锤子都用它
```

理由：v1.8.7 会删掉"世界球"这个入口，但**球形按钮这个控件仍然需要**（右键菜单要用）。**删入口 ≠ 删控件。**

## 四、需要的美术

- **🔨 锤子球形图标**（低多边形风格，与项目一致）。
  - 可以让助手用 `codeart2d` 生成（48×48 PNG，放在 `art/ui/`），也可以你自己画。
  - **命名规范**：`art/ui/hammer-ball.png`，由 `UIKit.get_icon("hammer-ball", UIKit.Art.UI)` 读取。

## 五、涉及文件

- `scripts/ui/hex_map_view.gd`（右键信号）
- `scripts/ui/views/view_world_page.gd`（右键菜单 + 修建浮窗）
- `scripts/ui/ui_kit.gd`（`bubble_button` → 泛化为 `sphere_button`）
- **删**：`view_world_page.gd` 里旧的右侧规划面板（信息页 / 地块规划页）

## 六、验收

1. 右键地块 → 菜单出现在鼠标附近；点 🔨 → 浮窗出现。
2. 列表能看效果与生产力条件；生产力不足的条目**提示但仍可加入队列**（保持现有行为）。
3. **未选中条目时 `修建` 是灰的**；选中后亮起；`取消` 任何时候都能按。
4. 修建成功后，地块上出现建筑标记（绘制层已有）。
5. **旧的右侧规划面板已删**，且 `管理` 页里的修建入口**也不再需要**（那是 v1.8.7 的收尾）。
6. `跑自检.bat` → 12/12（引用旧规划面板的测试预期要同步改）。
