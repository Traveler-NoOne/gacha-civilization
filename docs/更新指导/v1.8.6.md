# v1.8.6 · 科技树浮窗（左上角）+ 日志浮窗（右上角）

## 一、目标

把**科技树**和**日志**从"全屏页面"改成"大世界上的浮窗"，并把入口搬到角落。

## 二、设计

### 科技树

- **入口**：**左上角**一个按钮（文字按钮即可；以后可以换成图标）。
- **形态**：点开后**独立浮窗**（不遮满屏，四周看得到地图）。
- **内容**：从 `view_manage_page.gd` 的**中控区 → 科技树**整块搬出来，功能不变（能看、能解锁、消耗不变）。
- 搬完之后，**管理页里的科技树入口就可以删了**（它是 v1.8.7 删管理入口的前置条件之一）。

### 日志

- **入口**：**右上角**，用 **image 按钮**（**书本图标**）代替文字。
- **形态**：**居中的大浮窗**，但**上下左右各留一点边**——**故意露出底下的地图**。
- **为什么要留边**：这是用"看得见下面的世界"来**暗示它是一个浮窗、而不是把世界切走了**。

## 三、需要的美术

- **书本图标**（低多边形风格，48×48 PNG，`art/ui/book.png`）。
  - 可以让助手用 `codeart2d` 生成，也可以你自己画。
  - **可以一并对齐已有的两张世界球图**（`world-ball-s/l.png`）的风格，让角落按钮看起来是一套。

## 四、涉及文件

- `scripts/ui/game_screen.gd`（左上角、右上角两个按钮）
- `scripts/ui/views/log_view.gd`（从全屏页改成浮窗：尺寸/位置 + 关闭按钮）
- 科技树浮窗（从 `view_manage_page.gd` 的中控区拆出，建议单独成 `scripts/ui/panels/tech_panel.gd`）
- `view_manage_page.gd`（移除科技树那一块）

## 五、验收

1. 左上角按钮 → 科技树浮窗；能正常解锁科技、消耗正确。
2. 右上角书本按钮 → 日志浮窗；**四周能看见地图**。
3. 两个浮窗都能关；关闭后回到纯地图。
4. 管理页里的科技树入口已移除，且**没有功能丢失**（≥ 12/12）。
5. 试玩确认：两个浮窗打开时，地图的拖动/缩放不受影响或被正确阻断（按你手感定）。
