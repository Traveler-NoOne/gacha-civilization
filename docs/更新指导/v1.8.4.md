# v1.8.4 · 据点管理窗口

## 一、目标

右侧弹出**据点管理窗口**。左键点我方领地块时打开它（接上 v1.8.2 留下的空实现）。

## 二、设计

```
            ┌───────────────────────────────────┐
  [信息][政事][人力]  ← 按钮排在窗口边缘**之外的上方**
            ├───────────────────────────────────┤
            │  上半段（随上面的按钮切换）：          │
            │    信息（默认）：掌控力 / 已用土地 / 据点明细 │
            │    政事：政事列表（可排入政事队列）        │
            │    人力：指派人力（原「人力管理」）        │
            ├───────────────────────────────────┤
            │  │        政事队列        │   ← 各自跑条
            │  ├───────────────────────┤
            │  │        规划队列        │   ← 各自跑条
            └───────────────────────────────────┘
```

- **上半段三个按钮**：`[信息]`（默认）`[政事]` `[人力]`——**按钮在窗口边框之外的上方**，不占窗口内部高度。
- **下半段两个队列**属于**同一块区域**，上下叠放，**各自带进度条**：
  - **政事队列**（上）= 政事，消耗**行政点数**
  - **规划队列**（下）= 建筑，消耗**生产力**（现有系统，只是搬了个显示位置）
- **「信息」只显示三样**：掌控力 / 已用土地 / 据点明细。
  （**地块明细不在这里**——它归 v1.8.2 的简约地块信息小窗。）

## 三、关键约束：本段**不要删**旧的右侧详情页

旧的右侧「规划面板（信息页 / 地块规划页）」**这个阶段必须留着**——因为**修建建筑的入口还在那儿**。它要到 **v1.8.5**（修建浮窗做好之后）才删。

> 总规则第 1 条：**不允许出现"玩家暂时没法建造"的中间态。**

## 四、涉及文件

- **新增** `scripts/ui/panels/stronghold_panel.gd`（窗口本体：三段上半 + 两队列下半）
- `scripts/ui/views/view_world_page.gd`（接收"点领地"信号 → 开窗）
- 复用 `view_manage_page.gd` 里现成的两块逻辑：**人力管理**（含"过滤无需人力的建筑"）、**规划队列显示**

## 五、验收

1. 点我方任一领地块 → 右侧窗口出现；点别处 → 关闭（或保持，按手感定）。
2. 三个上半段按钮都能切，内容正确。
3. **两个队列各自显示进度条**，进度随周期推进（政事队列要等 v1.8.3 的推进机制跑起来才看得到）。
4. **人力**能加减，且**经典民居/经典仓储/经典训练场地不出现在列表里**（v1.7.2 的成果不能回退）。
5. 旧的右侧规划面板**仍然可用**（修建还能点）。
6. `跑自检.bat` → 12/12。
