# v1.8.4 · 据点管理窗口

## 一、目标

右侧弹出**据点管理窗口**。左键点我方领地块时打开它（接上 v1.8.2 留下的空实现）。

## 二、设计

```
            ┌───────────────────────────────────┐
  [信息][政事][人力]  ← 按钮排在窗口边缘**之外的上方**
            ├───────────────────────────────────┤
            │  上半段（随上面的按钮切换）：          │
            │    信息（默认）：掌控力 / 已用土地 / 据点明细 │
            │    政事：政事列表（可排入政事队列）        │
            │    人力：指派人力（原「人力管理」）        │
            ├───────────────────────────────────┤
            │  │        政事队列        │   ← 各自跑条
            │  ├───────────────────────┤
            │  │        规划队列        │   ← 各自跑条
            └───────────────────────────────────┘
```

- **上半段三个按钮**：`[信息]`（默认）`[政事]` `[人力]`——**按钮在窗口边框之外的上方**，不占窗口内部高度。
- **下半段两个队列**属于**同一块区域**，上下叠放，**各自带进度条**：
  - **政事队列**（上）= 政事，消耗**行政点数**
  - **规划队列**（下）= 建筑，消耗**生产力**（现有系统，只是搬了个显示位置）
- **「信息」只显示三样**：掌控力 / 已用土地 / 据点明细。
  （**地块明细不在这里**——它归 v1.8.2 的简约地块信息小窗。）

## 三、关键约束：本段**不要删**旧的右侧详情页

旧的右侧「规划面板（信息页 / 地块规划页）」**这个阶段必须留着**——因为**修建建筑的入口还在那儿**。它要到 **v1.8.5**（修建浮窗做好之后）才删。

> 总规则第 1 条：**不允许出现"玩家暂时没法建造"的中间态。**

## 四、涉及文件

- **新增** `scripts/ui/panels/stronghold_panel.gd`（窗口本体：三段上半 + 两队列下半）
- `scripts/ui/views/view_world_page.gd`（接收"点领地"信号 → 开窗）
- 复用 `view_manage_page.gd` 里现成的两块逻辑：**人力管理**（含"过滤无需人力的建筑"）、**规划队列显示**

1. 点我方任一领地块 → 右侧窗口出现；点别处 → 关闭（或保持，按手感定）。
2. 三个上半段按钮都能切，内容正确。

## 七、实施记录（接手后补记，2026-10-09）

### 做了什么

- **新增 `scripts/ui/panels/stronghold_panel.gd`**（`class_name StrongholdPanel`）：
  按钮行在窗口**边框之外的上方**（`[信息][政事][人力] [✕]`）；上半段放进 `ScrollContainer` 并吃掉剩余高度（下半段两个队列才能稳定贴底）；下半段两条队列各带 `UIKit.bar` 跑条。
- **人力管理行做成 `static StrongholdPanel.build_labor_rows()`** —— 管理页与本窗口**共用同一份**（v1.7.2「过滤掉不需要人力的建筑」的规矩就在这一份里）。
- **世界页**：点我方领地块 → `_open_stronghold_panel()`（懒创建、固定 340×520、贴右侧）；`refresh()` 里若窗口开着则同步刷新内容。
- **关闭方式**：窗口右上角 ✕。**故意不"点别处就自动关"** —— 管理窗口不该因为你点了一下地图就消失。
- **不删**旧的右侧规划面板（修建入口还在那儿，v1.8.5 才搬走）。过渡期两者并存，新窗口盖在旧面板上。

### 三个坑（都值得记）

1. **「锚右上 + 负偏移」把窗口送到了屏幕外。**
   `set_anchors_preset(PRESET_TOP_RIGHT)` 是在 `add_child` **之前**调的 —— 那时还没有父节点可参照，
   于是 `position = (-356, 56)` 里的负值被当成**绝对坐标**，实测 `global_position = (-356, 56)`，白忙一场。
   **正解：锚点用 `PRESET_TOP_LEFT` + 绝对定位**（打开时按页宽算 `size.x - 356`），和"简约信息小窗"同一套做法。
2. **底色 0.97 不透明 → 旧面板的文字透上来**，看起来像"内容很暗、有鬼影"。
   浮层底色**必须完全不透明**（1.0），否则下面任何东西都会透上来。小窗也一并从 0.96 改成 1.0。
3. **建了节点却忘了挂上去**：`_refresh_decrees` 里把政事行 `row` 的内容都建好了，**却没写 `content_box.add_child(row)`** ✗
   → 界面上什么都没有，而且**不报错**（最难发现的一类）。
   > 教训：**"节点内容建好" ≠ "已经显示"**。加完内容顺手确认挂载那一行。
