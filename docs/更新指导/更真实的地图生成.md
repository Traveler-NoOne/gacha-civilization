# 更真实的地图生成（更新计划）

> 立项：2026-10-13。来源：`~/.commandcode/plans/realistic-map-generation.md`（调研 + 四档方案）。
> 本文是**正式的分段指导**：决定已拍板，按第四节的段推进；每段结束都必须可玩 + 一段一提交。

## 一、目标

把"每格一个哈希定死的地形"，换成**看起来像真实地理**的地图：成片的水域与海岸线、
有逻辑的山脉分布、干湿不同的植被带。

## 二、已拍板（四条）

| # | 决定 | 落地含义 |
| --- | --- | --- |
| 1 | **做到 A + B** | A：高程噪声 → 地形；B：湿度噪声 → 生物群系查表。侵蚀（C）按第 4 条另行处理 |
| 2 | **地形种类要扩，且分成「地形」与「地物」两层** | **平原 / 山丘 / 山脉 / 沙丘** 这类是**地形**；**草地 / 森林** 这类是**地物** → **分开两个字段存取**（见第三节） |

## 三、数据模型：地形 vs 地物（**本计划的核心改动**）

现在一格只有 `terrain`（水/树林/丘陵/荒地/平原，一个字段混着两类概念）。
本计划拆成两层：

| 字段 | 叫法 | 取值（示例） | 谁来读 |
| --- | --- | --- | --- |
| `terrain` | **地形**（地表形态 / 地貌） | `water`（水）· `plain`（平原）· `hill`（山丘）· `mountain`（山脉）· `dune`（沙丘）· `wasteland`（荒地） | 底色绘制、地形名、通行/建造规则（将来） |
| `cover` | **地物**（地表覆盖物） | `""`（裸地）· `grass`（草地）· `forest`（森林）· `swamp`（沼泽）… | 第二层绘制（叠在地形色之上）、资源分布（木头在森林…）、将来的采集/隐蔽等 |

**命名注意**：代码里 `feature` 已经被"特征物（资源点）"用了（`_draw_tile_features`）→
所以地物的字段名用 **`cover`**，别叫 `feature`，免得两处概念打架。

**兼容**：旧档的 `terrain` 里如果出现 `forest` 这种"其实是地物"的值 → 由第 2 段一并迁移/清理
（本计划采纳"老档直接删"的策略，所以迁移只对新档生效即可）。

**绘制层次（`hex_map_view` 现有 8 层）**：地形色在 ① 底色；地物建议并入 ②（与资源点同层，
或紧随其后单列一层），只要**不压过文字层**就行。

## 四、分段

### 第 1 段：高程噪声 → 地形（取代 `hash01`）

- 引入 **`FastNoiseLite`（Godot 4 内置，MIT，零依赖）**：用 `world_gen` 里缓存一份、按 `world_seed` 播种子。
- 做法（Red Blob《Making maps with noise functions》的 A 档部分）：
  1. 多倍频叠加：`FREQ = 0.14`（单位是"格"）、`fractal_octaves = 4`、`fractal_gain = 0.5`；
  2. **重塑**：`e = pow(e, 1.25)` —— 把中间高度往下压一点，让平原多些；
     （⚠️ 指数就是"水多不多"的旋钮，调大 → 水变多。第一版用了 `pow(e*1.15, 2.6)`，
     中值被压到 0.24，半张图都成了海，实测后改温和了。）
  3. 阈值切地形（第 1 段实测的分布 ≈ 水 33% / 平原 32% / 山丘 24% / 森林 12%）：
     `water < 0.36` · `plain < 0.50` · `hill < 0.62` · `forest < 0.72` · 其余 `wasteland`。
- **验收指标**：相邻格同地形的比例 —— 实测 **46%**（纯随机撒点约 20%）→ 说明地貌"成片"了 ✓

- **本段不碰地物**（`cover` 留在第 2 段引入），也不碰资源分布 → 改动面最小、能立刻看出"成片"效果。
- 硬约束：噪声是 `f(坐标, 种子)` → **天然满足**"扩张一致"（1.8.20.9 那条）✓

### 第 2 段：湿度 + 生物群系 + 地形/地物拆分 + 扩种类

- 再加一张噪声（**不同种子**）→ 湿度 `m`；用 `biome(e, m)` 查表（Red Blob 给了现成阈值表，改数字即可）。
- 落地第三节的两字段模型（`terrain` + `cover`），并扩展 `Consts.terrain_color / terrain_name`
  （以及新增一套 `cover_color / cover_name`）。
- 绘制：地形色在下、地物叠一层（内缩一圈的小六边形，地形色仍看得见）。
- 资源分布改为**按地貌**（木头←森林地物；煤/铜←山丘），仍然是 `f(坐标, 种子)`。
  原来还有一条"离中心 4 格以外零星撒木头"的距离规则 → 删掉（那是给"出生点保底"兜底的，
  现在出生点选址已经保证附近资源丰富，用不着了）。实测 1387 格里 270 个资源点（约每 5 格一个）。
- 顺带修一处旧的不一致：`generate()` 原来会把首都地块的地形**强行改成 `plain`**，
  于是可能出现"煤长在平原上"。现在**首都保留自己的真实地貌**（`choose_capital` 已经保证它非水，
  而且全项目对地形的依赖只有"是不是水"和绘制/命名，没有建造规则依赖地形类型，所以安全）。
  这条是新增的自检护栏"资源必须长在对应地貌上"当场抓出来的。

**出生点改造（用户增补，已并入本段）**：不再固定在世界中心，也不再靠"强制某块地长资源"的补丁。

- 删掉 `_ensure_basic_nearby()`（那个强制补丁）及其调用；
- 新增 `choose_capital(tiles)`：候选 = **非水**且离世界中心不超过「起始半径 × 0.78」（**不贴边境**）；
  得分 = 周围 3 格内**有资源的地块数**；取最高分，并列取离中心更近的。
  **全程不含随机** → 同一局永远选到同一格。
- 实测（种子 20240607）：出生点 `-3,0`（离中心 3 格，3 格内 16 个资源点）。

### 第 3 段：岛屿 / 大陆形状 —— ✅ 已完成

- 做法（Red Blob 那篇的"距离塑造"）：`e = lerp(e, 1 - d, 0.55)`，其中
  `d = 到世界中心的格距 / (起始半径 × 1.3)`，再 `clampf(d, 0, 1)` → 中间是陆、四周是海。
- **尺度必须用固定常量**（段文件里原本写的是按 `MAP_MAX_RADIUS` 算；实测发现那样不行 ✗：
  初始半径 21 / 上限 30 = 已经走到 70% 的位置，初始那张图会大半是海）。
  改成「起始半径 × 1.3」后：初始图有完整海岸线，扩张出去则是更深的海。
  **两种写法都是固定常量 → 都满足"扩张一致"那条约束**（实测扩张后已有地块逐字段未变 ✓）。
- **1.3 这个系数是"海岸线落在哪"的旋钮**：调小 → 初始图大半是海；调大 → 海岸线退到图外、看不出海。
- 实测（种子 20240607）：边缘含水 91%（223/246）、中心含水 0%（0/37）；
  "相邻格同地形比例"从 54% 升到 **78%**（大陆让地貌更成片）。
- 已知副作用（要改就说）：扩张出去的地块**多半是海** —— 若希望"扩建也能拿到陆地"，
  把 1.3 调大即可（代价是海岸线离初始边界更远）。

### 第 4 段（可选）：侵蚀 / 河流

- 按拍板 4：**固定最大范围的全局后处理**（用 `MAP_MAX_RADIUS` 跑一遍，而不是当前半径）。
- 参考思路：mewo2/terrain（MIT）的"高度场 → 侵蚀 → 河流"；
  另有一个**逐像素滤镜**式的实现（runevision 2026-03）可作轻量替代。
- 性能要实测：初始生成时要按最大规模算一遍。

## 五、验收（每段各自）

脚本能验的（扩展现有 `tests/seed_check`）：

- 同种子 → 同一张图 ✓（已有）
- 换种子 → 地图不同 ✓（已有）
- 扩张出来的一格与"一开始就生成这么大"一致 ✓（已有）
- **新增**：地形"成片"而不是随机撒点 —— 用"相邻格同地形比例"衡量，
  随机撒点约 20%（5 种地形），噪声地图应显著更高（那条断言给一个宽松下限即可）。

只能你来看的（照现有规矩，交给你手测）：

- 海/陆/丘陵是不是**成片**了、海岸线像不像样；
- 植被带（干湿分区）合不合理；
- 整体"像不像真实地理"。

> 建议顺手加一个**调试用 ASCII 地形小地图**（把 tiles 按坐标铺成字符画打一行行）→
> 新开一局就能在控制台"一眼看出地貌"，比跑游戏看截图快得多。要不要长期保留由你定。

## 六、性能 / 风险

- 每格 2~4 次噪声采样 × 倍频，量级很小；**第 4 段**按最大范围跑全局后处理时才是重头，需实测。
- 最容易踩的坑：**破坏 `f(坐标, 种子)` 的纯函数性**（岛屿塑造、侵蚀两处）→ 每段都跑"扩张一致"断言。
- 观感没有脚本能判 → 一段一段来，每段都能玩、都能看。
