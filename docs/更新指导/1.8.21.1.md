### 踩的坑（下次恢复旧脚本一定还会遇到）

1. **带 `class_name` 的脚本从 git 恢复后，必须先跑一次 `--import`**，否则全局类名没注册：
   报 `Compile Error: Identifier not found: TestUtil` → 依赖它的 `screenshot.gd` 一起编译失败 →
   退化成"`U.host` 不存在"的**二级错误**，最后表现为 **120 秒看门狗超时**（不是崩溃，最难认）。
   ```
   & $godot --headless --import --path <项目>
   ```
2. **`git checkout <ref> -- <path>` 会被安全网拦**（它要覆盖工作区）→ 改用 `git show <ref>:<path>` 提取内容落盘。
   写完要**把 `.gd` / `.tscn` 的行尾归一成 LF**（`.gitattributes` 是 `* text=auto eol=lf`），
   而 **`.bat` 必须留 CRLF**（cmd.exe 解析 LF 行尾的 .bat 会逐行丢一个字符）。
3. **"土地富余"的格子上不存在"不能修建"这一态** —— 想拍禁用态，就得挑土地已用满的格子（见上）。

## 补记（2026-10-13 晚，为 W1 准备基线时发现）

### ① `02e` 又偶发拍不到 —— 成因找到了，而且是个真 bug

为世界生成 W1 准备截图基线时，一次运行**只出了 44 张**，`02e_dialog_cheat_checked` 又没了
（1.8.21.1 修过一次"找不到就整棵树找"，但那次只治了"找的地方不对"，没治根因）。再跑一次又正常 → **偶发**。

**根因**：那个勾选框的**初始态来自持久化的全局设置**（`user://settings.cfg` 的 `[cheat] enabled`）。
**玩家自己开着作弊时**，脚本里 `button_pressed = true` **不产生变化 → `toggled` 不触发** →
二次确认弹窗压根不生成 → `02e` 拍不到、`02d` 拍到的是**普通反馈窗**（清单悄悄少一张，最难发现）。
> 时间线也吻合：用户玩过游戏（`settings.cfg` 里 `resolution=1920x1080 / fullscreen=true` 是他改的），
> 期间若把作弊开着，我下一次跑基线就会偶发失败；而那次失败跑完又把设置写回 `false`，于是"自己掩盖自己"。

**修法（两处）**：
1. **保证一定发生状态变化**：设 `button_pressed = true` 之前先 `set_pressed_no_signal(false)`
   —— 不管初始是什么，这一步都必然触发 `toggled`。
2. **测试不得改玩家的东西**（1.8.1b 那条规矩，截图脚本一直违反着）：
   脚本中途会开/关「作弊功能」，而它是**持久化**的 → 现在**开头记下原值、收尾还原**
   （原来是结尾无条件设 `false`，等于替玩家把作弊关掉）。

**验证（两个修复一起验）**：先把 `settings.cfg` 的作弊**设成 `true`**（= 偶发失败的条件）再跑 →
**照样 45 张**，且打印「已还原「作弊功能」设置为：true」→ 说明**既治了偶发、又没动玩家设置**；
再跑一次正常路径（初始 `false`）→ 45 张、跑完仍是 `false`。之后把设置放回用户原值。
