## 一、目标

把高程从"**一张噪声**"改成"**板块过程的结果**" ——
让地图上第一次出现**成条的山脉、海沟、裂谷、洋中脊**（而不是各处长一样的丘陵）。

## 二、做什么

### 2.1 S1 板块与边界（建议新建 `scripts/core/plates.gd`，别把 `world_gen.gd` 撑爆）

| 步 | 内容 |
| --- | --- |
| 1 | 在**死地图**（512×512 方格）上撒 **6~12 个板块种子**（数量按地图面积定，可用固定公式而不是随机数） |
| 2 | 每个板块给一个**运动矢量**（角度 + 速度） |
| 3 | 按**距离场**划分板块归属（方格上用 BFS 距离场即可，不必上 Voronoi 库） |
| 4 | 判**边界类型**：把边界像素两侧板块的运动矢量分解成**法向 / 切向**分量 → 相向 = **碰撞 / 俯冲**、相离 = **裂谷 / 洋中脊**、以切向为主 = **转换断层** |
| 5 | 生成**边界应力场**（沿边界有宽度，不能只是一条线） |

### 2.2 S2 高程合成

```
高程 = 低频噪声（给大陆/海洋的大形状）
      + 板块贡献（碰撞→山系 / 俯冲→海沟+岛弧 / 裂谷→凹陷 / 洋中脊→海底隆起）
```

- ⚠️ **山脉必须沿边界成条**：对边界应力做**一维平滑**（沿边界方向），否则会得到"孤立点峰"。
- ⚠️ 边界影响要有**衰减宽度**（离边界越远影响越小），否则山脉像一堵突然立起来的墙。

## 三、验收

1. **人看**：地图上能认出"**一条山脉**""**一条海沟**""**一道裂谷**"——而不是一堆散落的丘陵。
2. **同种子两次生成，`elevation` 逐位一致**（总纲 3.4 的确定性要求）。
3. 4 个无头自检全绿；截图对比说明"变了哪些张、为什么变"（这一段的图**本来就该大改**）。

- **不为"好不好玩"调参**（总规则第 8 条 + 用户明说不在乎地块平衡）。

### ✅ 第二步（S2 高程合成 → **已接进地图**）已完成（2026-10-13）

用户连续两轮未回"先玩 W1 还是接线"的选择题 → 我按"开工"的原意（计划已批准、目标要求逐段推进）**继续做了 S2**。
git 是安全网：要看 W1 的状态随时 `git checkout d277302`。

**做法（关键：保持"逐格纯函数"）**：现在的高度是 `f(一格坐标, 种子)`，所以板块也必须能"按一格直接问"，
不能先建整张参数图。于是 `Plates` 增加了一组**无网格原语**：

- `frame(seed)`：种子/运动矢量（按种子缓存），铺在"当前地图外接矩形 × 1.4"的盒子里 → **边界真的穿过地图**；
- `plate_at_point(像素点)`：最近种子（并列取小的 → 确定）；
- `boundary_for(格)`：**这一格实际会用到的那条边界**（3 格内、相向/相离里最强的一条）；
- `effect_at(格, base, seed)`：板块对高度的贡献（**可正可负**）——
  相向 + 这一侧高（陆）→ **山系**；相向 + 这一侧低（海）→ **海沟**；
  相离 + 陆 → **裂谷**；相离 + 海 → **洋中脊**；错动 → 0；离边界越远越弱（3 格衰减）。
- `world_gen.elevation_of()` 末尾叠上它，并 `clamp(0,1)`。**地形/地物阈值、湿度那套全没动**。

**实测（seed 20240607，半径 21）**：

| 指标 | W2 前 | W2 后 |
| --- | --- | --- |
| **山脉**格数 | 16 | **31** |
| 水 / 平原 / 丘陵 | 589 / 494 / 279 | 713 / 371 / 267 |
| 相邻格同地形比例 | 73% | **75%** |
| **河流格**数（相邻率） | 21（29%） | **28（43%）** |
| 大陆形状 | 边缘含水 91% / 中心 0% | 边缘 92% / 中心 0% |

> 河流那两行是**意外收获**：板块造成的高低起伏让汇流更容易攒起来，水系比之前更连了（W4 会正式做河流）。
