## 一、目标

把高程从"**一张噪声**"改成"**板块过程的结果**" ——
让地图上第一次出现**成条的山脉、海沟、裂谷、洋中脊**（而不是各处长一样的丘陵）。

## 二、做什么

### 2.1 S1 板块与边界（建议新建 `scripts/core/plates.gd`，别把 `world_gen.gd` 撑爆）

| 步 | 内容 |
| --- | --- |
| 1 | 在**死地图**（512×512 方格）上撒 **6~12 个板块种子**（数量按地图面积定，可用固定公式而不是随机数） |
| 2 | 每个板块给一个**运动矢量**（角度 + 速度） |
| 3 | 按**距离场**划分板块归属（方格上用 BFS 距离场即可，不必上 Voronoi 库） |
| 4 | 判**边界类型**：把边界像素两侧板块的运动矢量分解成**法向 / 切向**分量 → 相向 = **碰撞 / 俯冲**、相离 = **裂谷 / 洋中脊**、以切向为主 = **转换断层** |
| 5 | 生成**边界应力场**（沿边界有宽度，不能只是一条线） |

### 2.2 S2 高程合成

```
高程 = 低频噪声（给大陆/海洋的大形状）
      + 板块贡献（碰撞→山系 / 俯冲→海沟+岛弧 / 裂谷→凹陷 / 洋中脊→海底隆起）
```

- ⚠️ **山脉必须沿边界成条**：对边界应力做**一维平滑**（沿边界方向），否则会得到"孤立点峰"。
- ⚠️ 边界影响要有**衰减宽度**（离边界越远影响越小），否则山脉像一堵突然立起来的墙。

## 三、验收

1. **人看**：地图上能认出"**一条山脉**""**一条海沟**""**一道裂谷**"——而不是一堆散落的丘陵。
2. **同种子两次生成，`elevation` 逐位一致**（总纲 3.4 的确定性要求）。
3. 4 个无头自检全绿；截图对比说明"变了哪些张、为什么变"（这一段的图**本来就该大改**）。

## 四、范围外

- **不做气候**（W3）、**不做河流**（W4）。
- **不为"好不好玩"调参**（总规则第 8 条 + 用户明说不在乎地块平衡）。

## 五、风险与提醒

- ⚠️ **这一段的观感会大改，但不一定"更好看"**（山脉有了，可气候/河流还没上，会显得光秃秃）。
  总纲已写明：按 W2→W3→W4 走；若中途觉得难受，可以调成"先在现有噪声高程上做 W3+W4、最后再换 W2"，
  代价是**换高程源时要重调一次气候参数**。
- 板块数量太少会显假（整张图就几块）；太多则边界碎。**这个数字属于可逆参数**，助理试出来给用户看。
