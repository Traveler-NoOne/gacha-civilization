# 世界生成 · W8 —— 世界地图（只读鸟瞰图）

> 状态：⬜ 未开始（用户将统一审阅）
> 依赖：W7
> 总纲：[世界生成-过程模拟.md](./世界生成-过程模拟.md)（第八节 8.1 的"疆域感"一行）

## 一、目标

补上"**一次只显示一个世界**"带来的**疆域感损失**：

> 在**日志 → 记录**里加一个「**世界地图**」按钮；点了渲染一张
> **去掉所有功能用图像、只画地形 / 建筑 / 单位**的图，**可以查看、可以保存**；
> **只读，不存在任何实际控制功能。**

（用户 2026-10-13 原话。）

## 二、做什么

| # | 内容 |
| --- | --- |
| 1 | 入口：**日志浮窗 → 记录页** 里加一个「世界地图」按钮 |
| 2 | 渲染：把所有世界的**地形 / 建筑 / 单位**画到一张图上；**不画**任何功能用图像（按钮、高亮、描边提示、迷雾以外的 UI 等） |
| 3 | 内容：**地形**（地貌+地物+水域/河流）、**建筑**、**单位**；**不建议**画敌人（用户没要求；要画的话得单独确认） |
| 4 | 交互：**可查看（缩放/平移）**、**可保存**（导出 PNG） |
| 5 | ⚠️ **限制导出尺寸**：拼到十几块后整图会到**几万像素** → 超限时**降采样**或**分块导出** |
| 6 | ⚠️ 明确"**只读**"：点了不能做任何操作（不做单位选择、不做修建）——避免变成一个半成品界面 |

## 三、验收

1. 拼了 N 块世界后，点「世界地图」能**看到全貌**（看得出"我的疆域长了几个方向"）。
2. 导出的 PNG **能保存成功**，且**尺寸受控**（不出现几万像素的怪物图）。
3. **它不能操作任何东西**（点上去没有反应，或明确提示"仅供查看"）。
4. 4 个无头自检全绿；观感交用户手测。

## 四、范围外

- **不做交互式大地图**（不做"在大地图上直接下令"）—— 那是另一个量级的工程，且会与 W7 的"一次只显示一个世界"打架。
- **不做战争迷雾的全局版**（只画已知的即可；具体口径实现时再定）。
- **不做分享/上传**（只做"保存到本地"）。

## 五、风险

- **性能**：一次性渲染几万格会卡 → 要**分帧渲染**或**先渲染成一张离屏图**再显示；
  这也是"为什么要限制尺寸"的原因。
- 这一段**纯粹是锦上添花**：如果 W7 之后用户觉得"其实不需要"，**可以直接砍掉**。
