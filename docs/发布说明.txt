========================================================
  抽卡文明 · 可玩 Demo — v1.7.2（纪念版）
========================================================

本作是把设计文档《抽卡文明》里已经写清楚的部分做出来的
一个 Godot 4 原型：能跑起来、能玩一轮。

--------------------------------------------------------
一、怎么运行
--------------------------------------------------------
· 双击「抽卡文明.exe」即可，免安装、免联网。
· 若首次运行被 Windows SmartScreen 拦截：
  点「更多信息」→「仍要运行」。
  （本程序未做代码签名，出现该提示属正常现象。）

--------------------------------------------------------
二、操作
--------------------------------------------------------
· 数字键 1~5 ：切换 管理 / 至宝 / 世界泡 / 日志 / 世界
· 空格       ：结束当前周期（回合）
· Esc        ：关闭弹窗
· 世界地图   ：左键拖动平移、滚轮缩放、
               点击地块查看详情、中键回到首都

--------------------------------------------------------
三、这一版在玩什么
--------------------------------------------------------
· 三卡池 = 三个文明尺度：轮换（个体）/ 资源（领地）/
  发展（范式）。抽卡不花钱，代价是**地图上多出敌人**。
· 一级按钮「世界泡」下有三个子系统：召唤 / 打捞 / 发展。
· 开局赠送 5★ 公民「格蕾修」。
· 核心循环：每点一次「结束周期」结算一轮——
  建筑产出 → 维护消耗 → 人口增长 → 世界演化 →
  货币结算 → 单位经验 → 自动存档。

--------------------------------------------------------
四、这一版没有做的（诚实说明）
--------------------------------------------------------
· 局内战棋地图（战斗为抽象结算，无格子战场）
· 音效与背景音乐（完全没有音频）
· 正式美术（全部为几何图形 / 简单图标占位）
· 教程、多据点、范式科技树等（详见项目 README）
